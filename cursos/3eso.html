Aplicación, Datos e Inteligencia

Saberes básicos BOJA: desarrollo de aplicaciones web, IA y Big Data, scraping ético, ciberseguridad, protección de datos y propiedad intelectual. Metodología ABP.

UD1 · Desarrollo de apps web

HTML5 semántico, CSS3 responsive y JS vanilla. Accesibilidad y usabilidad.

UD2 · Big Data e IA básica

Conceptos de datos masivos, aprendizaje automático y ética algorítmica.

UD3 · Scraping y tratamiento de datos

Obtención, limpieza y visualización de datos con herramientas libres (Python).

UD4 · Ciberseguridad y privacidad

RGPD/LOPDGDD, contraseñas, amenazas y hábitos digitales seguros.

UD5 · Propiedad intelectual y licencias

Derechos de autor, Creative Commons y cultura de código abierto.

UD6 · Proyecto integrador (ABP)

App web con datos reales, IA o IoT, documentada bajo licencia abierta.

Proyecto integrador · "Mi app con propósito"

ABP: desarrollar una aplicación web que resuelva una necesidad del centro (ej. agenda de reciclaje, mapa de sombras, consulta de datos abiertos). Incluye scraping ético, privacidad por diseño y licencia CC BY-NC 4.0.
