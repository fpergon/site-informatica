Introducción al software. Clasificaciones y aplicaciones

Nota didáctica Esta sesión inicial contextualiza el software de aplicación dentro del ecosistema de programas. Es fundamental que el alumnado comprenda la diferencia entre software de sistema y de aplicación para situar el procesador de texto en su contexto correcto.

Introducción

Antes de profundizar en los procesadores de texto, es necesario entender qué es el software y cómo se clasifica. El software es el conjunto de programas que permiten realizar tareas específicas en un ordenador. En esta sesión conoceremos las diferentes categorías de software y nos centraremos en las aplicaciones de productividad.

Clasificación del software

  • Software de sistema: Gestiona el hardware y proporciona un entorno para ejecutar programas. Ejemplos: sistemas operativos (Windows, macOS, Linux), controladores, utilidades.
  • Software de aplicación: Permite al usuario realizar tareas específicas. Ejemplos: procesadores de texto, hojas de cálculo, navegadores web, editores de imagen.
  • Software de desarrollo: Utilizado para crear otros programas. Ejemplos: editores de código (VS Code), compiladores, IDEs.
  • Software de entretenimiento: Videojuegos, reproductores multimedia, aplicaciones de streaming.

Aplicaciones de propósito general vs. específico

  • Propósito general: Sirven para múltiples tareas (procesadores de texto, hojas de cálculo, navegadores).
  • Propósito específico: Diseñadas para un sector o profesión concreta (software médico, CAD para ingenieros, software contable).
Software propietario vs. libre Microsoft Office es software propietario (de pago, código cerrado). Google Docs y LibreOffice son alternativas: Google Docs es gratuito y basado en la nube; LibreOffice es gratuito y de código abierto. Todos permiten crear documentos similares, pero difieren en funciones y ecosistema.

Aplicaciones de escritorio vs. web

  • Escritorio: Se instalan en el ordenador. Funcionan sin conexión a Internet. Ejemplo: Microsoft Word, LibreOffice Writer.
  • Web (nube): Se ejecutan en el navegador. Requieren conexión a Internet. Ventajas: colaboración en tiempo real, acceso desde cualquier dispositivo. Ejemplo: Google Docs.

Software colaborativo

El software colaborativo permite que varias personas trabajen en el mismo documento simultáneamente:

  • Google Docs: Procesador de texto colaborativo con comentarios, sugerencias y control de versiones.
  • Microsoft 365: Suite completa con SharePoint y OneDrive para colaboración empresarial.
  • Notion: Herramienta todo-en-uno para documentación, wikis y gestión de proyectos.
Actividad exploratoria Abrir Google Docs (docs.google.com) y familiarizarse con la interfaz: barra de herramientas, menú de archivo, reglas, barra de estado. Crear un documento vacío y escribir un párrafo de al menos 100 palabras sobre qué esperas aprender en esta unidad.

Procesadores de texto: formatos de página, párrafo y carácter

Introducción

El dominio del formato es la clave para crear documentos profesionales. En esta sesión aprenderemos a controlar cada aspecto visual de un documento: desde el tamaño del papel hasta la última coma del texto. Comenzaremos con los formatos de carácter, continuaremos con los párrafos y finalizaremos con la configuración de la página.

Formatos de carácter

Los formatos de carácter afectan directamente al texto seleccionado:

  • Fuente (tipografía): Arial, Times New Roman, Calibri, Verdana, Georgia. La elección influye en la legibilidad y el tono del documento.
  • Tamaño: Se mide en puntos (pt). Un punto equivale a 1/72 de pulgada. Tamaño normal: 11-12pt. Títulos: 14-24pt.
  • Estilo: Negrita (bold), cursiva (italic), subrayado, tachado.
  • Color: Color del texto. Usar con moderación y contraste suficiente.
  • Efectos: Superíndice, subíndice, sombra, contorno.
Consejo de diseño No uses más de 2-3 fuentes diferentes en un documento. Usa una fuente para títulos y otra para el cuerpo del texto. Asegúrate de que ambas sean legibles tanto en pantalla como en papel.

Formatos de párrafo

Los formatos de párrafo controlan la disposición del texto en bloque:

  • Alineación: Izquierda (predeterminada), centrada, derecha, justificada.
  • Interlineado: Espacio entre líneas. Simple (1,0), 1,5 líneas, Doble (2,0).
  • Indicación: Espacio antes y después del párrafo.
  • Sangría: Primer línea (clásica) o francesa (todas menos la primera).
  • Bordes y sombras: Líneas alrededor del párrafo o efecto de sombra.

Formatos de página

Estos formatos afectan a todo el documento:

  • Tamaño del papel: A4 (210 × 297 mm) es el estándar europeo. Carta (216 × 279 mm) en EE.UU.
  • Orientación: Vertical (retrato) u horizontal (paisaje).
  • Márgenes: Superior, inferior, izquierdo, derecho. Márgenes estándar: 2,5 cm.
  • Encabezado y pie de página: Información que se repite en cada página (título, número de página, fecha).
Regla de oro Un documento profesional tiene márgenes uniformes, interlineado consistente y una jerarquía visual clara entre títulos, subtítulos y cuerpo de texto. La coherencia visual es tan importante como el contenido.

Actividad práctica

En Google Docs, crear un documento "Carta formal" que incluya:

  1. Formato de página A4 con márgenes de 3 cm.
  2. Encabezado con el nombre del alumno y fecha.
  3. Pie de página con número de página.
  4. Un párrafo de cuerpo con interlineado 1,5 y texto justificado.
  5. Un título con fuente de 16pt en negrita.
  6. Un párrafo con sangría francesa.

Imágenes y tablas: inserción, configuración y estilos

Introducción

Un documento profesional no solo contiene texto. Las imágenes enriquecen visualmente el contenido y las tablas organizan datos de forma clara y estructurada. En esta sesión aprenderemos a insertar, configurar y dar estilo tanto a imágenes como a tablas dentro de un procesador de texto.

Inserción de imágenes

Existen varias formas de añadir imágenes a un documento:

  • Desde el equipo: Seleccionar archivo de imagen (JPEG, PNG, GIF, SVG).
  • Por URL: Insertar imagen directamente desde una dirección web.
  • Desde la galería: Google Docs ofrece imágenes de stock gratuitas.
  • Captura de pantalla: Insertar directamente desde el portapapeles.

Configuración de imágenes

Una vez insertada, la imagen se puede configurar de varias maneras:

  • Texto alrededor: En línea, ajuste de texto (wrap), delante del texto, detrás del texto.
  • Tamaño: Arrastrar esquinas (mantener proporciones) o definir medidas exactas.
  • Recorte: Eliminar partes no deseadas de la imagen.
  • Ajustes de imagen: Brillo, contraste, saturación, filtros artísticos.
  • Posición: Alineación respecto al texto o a la página.
Buenas prácticas Usa imágenes de alta resolución pero optimizadas para web (máximo 150 DPI para impresión). Añade siempre un texto alternativo descriptivo (alt text) para accesibilidad. Mantén las proporciones al redimensionar.

Inserción y configuración de tablas

Las tablas organizan datos en filas y columnas:

  • Crear tabla: Seleccionar número de filas y columnas (o dibujar la tabla).
  • Fusionar celdas: Unir dos o más celdas en una sola.
  • Dividir celdas: Separar una celda en varias.
  • Insertar/eliminar filas y columnas: Ajustar el tamaño de la tabla.
  • Distribuir filas/columnas: Uniformizar el tamaño.

Estilos de tabla

La apariencia visual de las tablas se puede personalizar:

  • Bordes: Estilo (sólido, punteado, discontinuo), grosor, color.
  • Relleno de celdas: Color de fondo para filas, columnas o celdas específicas.
  • Estilos predefinidos: Google Docs ofrece diseños automáticos con colores alternos.
  • Alineación en celdas: Horizontal (izquierda, centro, derecha) y vertical (arriba, centro, abajo).
  • Dirección del texto: Horizontal o vertical dentro de la celda.
Consejo profesional Para tablas con muchos datos, usa colores alternados en las filas (banding) para facilitar la lectura. El encabezado debe destacar visualmente del resto de filas.

Actividad práctica

Crear un "Informe de inventario" que incluya:

  1. Una imagen con texto alrededor y recorte personalizado.
  2. Una tabla de 5×4 con encabezados con estilo y filas con colores alternos.
  3. Una segunda tabla con celdas fusionadas en el encabezado.
  4. Al menos 2 imágenes con diferentes configuraciones de ajuste de texto.

Columnas y secciones: diseño de publicaciones tipo revista

Introducción

Los documentos más elaborados, como revistas, boletines o folletos, utilizan diseños multicolumna y secciones con formatos independientes. En esta sesión aprenderemos a crear publicaciones profesionales con el diseño visual de una revista utilizando las herramientas de columnas y secciones del procesador de texto.

Diseño en columnas

Las columnas permiten dividir el espacio de la página en varias secciones verticales:

  • Columnas iguales: El texto se distribuye uniformemente en 2, 3 o más columnas.
  • Columnas desiguales: Una columna más ancha (principal) y otra más estrecha (lateral).
  • Separación entre columnas: Espacio libre entre columnas para mayor legibilidad.
  • Línea separadora: Opcionalmente, se puede añadir una línea vertical entre columnas.

Ejemplo práctico: Un boletín informativo con 2 columnas: la izquierda con noticias principales y la derecha con información complementaria.

Diseño de revistas Las revistas profesionales suelen usar diseños de 3 columnas con imágenes que "rompen" las columnas (texto alrededor). Esto crea un ritmo visual dinámico y atractivo para el lector.

Secciones

Las secciones permiten tener diferentes formatos de página en un mismo documento:

  • Cambiar de sección: Insertar un salto de sección para aplicar formatos diferentes.
  • Tipo de salto: Página siguiente, página par, página impar, continuo.
  • Formatos independientes: Cada sección puede tener sus propios márgenes, orientación, encabezado/pie y numeración.
  • Conexión entre secciones: Opción de "igual que la anterior" para mantener coherencia.

Elementos de diseño editorial

Para crear publicaciones tipo revista, combinaremos varios elementos:

  • Cabeceras destacadas: Títulos grandes con fuentes impactantes.
  • Bajadas (subtítulos): Texto explicativo bajo el título principal.
  • Citas destacadas: Frases enmarcadas con diseño especial.
  • Cajas de texto: Recuadros con información complementaria.
  • Textos de animación (drop caps): Letra capital grande al inicio del artículo.
Herramienta útil Google Docs permite crear diseños en columnas desde Formato → Columnas. Para secciones, usa Insertar → Salto → Salto de sección. En LibreOffice Writer, la función es similar pero con más opciones de personalización.

Actividad práctica

Diseñar un "Boletín informativo" de 2 páginas:

  1. Portada con título llamativo, imagen principal y bajada.
  2. Interior con diseño de 2-3 columnas.
  3. Al menos un artículo con imagen que rompa las columnas.
  4. Una sección con formato diferente (por ejemplo, un recuadro de noticias rápidas).
  5. Encabezado con el nombre del boletín y número de página.

Estilos e índices: estilos predefinidos y personalizados. Tabla de contenidos

Introducción

Los estilos son la herramienta más poderosa de un procesador de texto para crear documentos coherentes y profesionales. Permiten aplicar formato de forma consistente y generar automáticamente índices de contenidos. En esta sesión dominaremos el uso de estilos y la creación de tablas de contenidos.

¿Qué son los estilos?

Un estilo es un conjunto predefinido de formatos de carácter y párrafo que se aplican de forma conjunta. En lugar de formatear cada título manualmente, aplicamos un estilo que garantiza consistencia:

  • Título 1: Para títulos principales de capítulo.
  • Título 2: Para secciones dentro del capítulo.
  • Título 3: Para subsecciones.
  • Normal: Para el cuerpo del texto.
  • Cita: Para citas textuales.
Ventaja clave Si modifies el estilo "Título 1" (cambias la fuente, el tamaño o el color), todos los textos con ese estilo se actualizarán automáticamente en todo el documento. Esto ahorra tiempo y evita inconsistencias.

Crear estilos personalizados

Además de los estilos predefinidos, puedes crear los tuyos propios:

  1. Seleccionar un párrafo con el formato deseado.
  2. En el panel de estilos, hacer clic en "Crear estilo".
  3. Asignar nombre y guardar.
  4. El nuevo estilo aparecerá en la lista para uso futuro.

Tabla de contenidos automática

Si has utilizado estilos de título correctamente, puedes generar una tabla de contenidos automática:

  1. Colocar el cursor donde se desea insertar la tabla de contenidos.
  2. Insertar → Tabla de contenidos.
  3. Seleccionar el estilo deseado.
  4. La tabla se genera automáticamente con los títulos y sus números de página.

Para actualizar: clic derecho sobre la tabla → "Actualizar tabla de contenidos".

Consejo práctico Antes de crear la tabla de contenidos, revisa que todos los títulos tengan el estilo correcto asignado. Si un título no aparece en la tabla, probablemente tiene el estilo "Normal" en lugar de un estilo de título.

Actividad práctica

Crear un documento académico con:

  1. Al menos 3 niveles de títulos con estilos asignados.
  2. Un estilo personalizado para "Definición" o "Ejemplo".
  3. Tabla de contenidos automática en la primera página.
  4. Actualizar la tabla después de modificar algún título.
  5. Numeración automática de páginas que empiece en la segunda página.

Plantillas: documentos reutilizables como punto de partida

Introducción

Las plantillas son documentos prediseñados que sirven como punto de partida para crear nuevos documentos con una estructura y formato ya establecido. En esta sesión aprenderemos a utilizar plantillas existentes y a crear las nuestras propias para optimizar nuestro trabajo con procesadores de texto.

¿Qué son las plantillas?

Una plantilla es un archivo que contiene diseño, formato, texto e incluso fórmulas predefinidas. Al crear un documento a partir de una plantilla, se genera una copia editable sin modificar el original:

  • Plantillas de Google Docs: Accesibles desde docs.google.com → Galería de plantillas.
  • Plantillas de Word: Archivos .dotx que se abren como documentos nuevos.
  • Plantillas de LibreOffice: Archivos .ott con el mismo propósito.

Tipos de plantillas habituales

  • Cartas y correspondencia: Formato oficial con encabezado, dirección, cuerpo y despedida.
  • Informes: Estructura con portada, índice, capítulos y conclusiones.
  • CV (Curriculum Vitae): Formato con secciones de experiencia, formación y habilidades.
  • Propuestas comerciales: Estructura persuasiva con problemas, soluciones y presupuesto.
  • Facturas: Documentos con tablas de productos, IVA y totales.
  • Contratos: Texto legal con cláusulas predefinidas.
¿Cuándo usar plantillas? Las plantillas son ideales cuando necesitas crear documentos recurrentes con la misma estructura: informes mensuales, cartas formales, facturas o presentaciones. Ahoran tiempo y garantizan consistencia visual.

Crear una plantilla personalizada

  1. Diseñar el documento con todos los formatos necesarios (márgenes, estilos, encabezados).
  2. Incluir textos de ejemplo o instrucciones (marcadores de posición).
  3. Guardar el archivo con extensión de plantilla (.dotx en Word, .ott en LibreOffice).
  4. En Google Docs: guardar como plantilla en la carpeta de plantillas.

Marcadores de posición

Los marcadores de posición son textos que indican dónde el usuario debe escribir contenido específico:

  • [Nombre del autor]
  • [Fecha del informe]
  • [Insertar imagen aquí]
  • [Descripción del producto]
Actividad creativa Crear una plantilla de "Informe escolar" que incluya: portada con marcadores de posición, tabla de contenidos, secciones predefinidas (Introducción, Desarrollo, Conclusiones), pie de página con numeración y espacio para imágenes.

Exportación e importación. Formatos: DOCX, PDF, ODT. Comentarios

Introducción

Un documento solo es útil si se puede compartir y utilizar en otros entornos. En esta sesión aprenderemos a exportar e importar documentos en diferentes formatos, y a utilizar el sistema de comentarios para la revisión y colaboración.

Formatos de exportación

  • DOCX: Formato estándar de Microsoft Word. Compatible con la mayoría de procesadores. Ideal para compartir con usuarios que no usan Google Docs.
  • PDF (Portable Document Format): Formato que preserva el diseño exacto del documento. No se puede editar directamente. Ideal para impresión y distribución oficial.
  • ODT (OpenDocument Text): Formato abierto utilizado por LibreOffice. Compatible con múltiples plataformas.
  • RTF (Rich Text Format): Formato de texto enriquecido compatible con casi todos los procesadores. Pierde algunas funciones avanzadas.
  • TXT: Texto plano sin formato. Útil para notas o código.
  • EPUB: Formato para libros electrónicos. Ideal para documentos largos destinados a lectura en dispositivos móviles.
¿Cuándo usar cada formato? DOCX: Edición colaborativa. PDF: Distribución final, impresión, envío oficial. ODT: Compatibilidad con software libre. TXT: Notas rápidas, código fuente.

Sistema de comentarios

Los comentarios permiten la revisión y colaboración sin modificar el texto original:

  • Añadir comentario: Seleccionar texto → Comentar (o Ctrl+Alt+M).
  • Responder: Crear hilos de conversación sobre un comentario.
  • Aceptar/Rechazar: En modo sugerencias, aceptar o rechazar cambios propuestos.
  • Resolver: Marcar un comentario como resuelto cuando se ha atendido.
  • Exportar con comentarios: Al exportar a PDF, se pueden incluir o excluir los comentarios.
Flujo de trabajo recomendado 1. Elaborar el documento en Google Docs (nube). 2. Compartir con el profesor/compañeros para comentarios. 3. Aceptar las sugerencias. 4. Exportar a PDF para la entrega final.

Importar documentos

También es posible importar documentos desde otros formatos:

  • Subir un archivo DOCX, ODT o TXT a Google Drive.
  • Abrirlo con Google Docs (se convierte automáticamente).
  • Importar PDF: Google Docs permite importar el contenido de un PDF como imagen o texto.

Actividad práctica

  1. Crear un documento en Google Docs y exportarlo a DOCX, PDF y ODT.
  2. Abrir cada archivo exportado y verificar que se abre correctamente.
  3. Compartir el documento con un compañero y añadir al menos 3 comentarios.
  4. Resolver los comentarios y exportar el documento final a PDF.

Proyecto final: documento profesional completo con todas las funciones trabajadas

Proyecto de unidad Esta sesión está dedicada al desarrollo del proyecto final de la UD2. Cada alumno deberá crear un documento profesional que integre todas las competencias trabajadas a lo largo de las 7 sesiones anteriores.

Enunciado del proyecto

Crear un "Boletín informativo digital" de 4-6 páginas sobre un tema de actualidad tecnológica. El documento deberá incluir los siguientes elementos:

  • Portada: Título, imagen principal, bajada, fecha y autor.
  • Tabla de contenidos automática generada con estilos de título.
  • Al menos 3 artículos con diseño de columnas (2-3 columnas).
  • Imágenes con diferentes configuraciones de ajuste de texto.
  • Al menos 2 tablas con estilos personalizados.
  • Cita destacada con formato especial.
  • Encabezado y pie de página con numeración.
  • Al menos 2 estilos personalizados creados por el alumno.
  • Formato de página: A4 con márgenes configurados.
Criterios de evaluación El proyecto se evaluará en función de: correcta aplicación de formatos (25%), uso de estilos (20%), diseño visual y composición (20%), contenido y calidad del texto (20%), y uso de funciones avanzadas (15%).

Temas sugeridos

  • Inteligencia Artificial: presente y futuro.
  • Cambio climático y tecnología verde.
  • Las 5G y su impacto en la sociedad.
  • Realidad virtual y aumentada en la educación.
  • Ciberseguridad: amenazas y protecciones.
  • El comercio electrónico en España.

Entrega

El proyecto se entregará en dos formatos:

  1. PDF: Versión final para impresión y evaluación.
  2. DOCX o enlace de Google Docs: Para revisión de la estructura y uso de estilos.

Fecha de entrega: indicada por el profesorado.
