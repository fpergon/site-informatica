Algoritmos y diagramas de flujo. Definición, tipos de figuras, convenciones

Nota didáctica Esta sesión inicial es la puerta de entrada al mundo de la programación. Es fundamental que el alumnado comprenda que programar no es "escribir código", sino "resolver problemas de forma lógica y estructurada". Los algoritmos y diagramas de flujo son herramientas de pensamiento que van más allá de cualquier lenguaje de programación.

Introducción

Programar es dar instrucciones a un ordenador para que resuelva un problema. Pero antes de escribir código, necesitamos planificar la solución. Los algoritmos y los diagramas de flujo son las herramientas fundamentales para esta planificación. En esta sesión aprenderemos a diseñar algoritmos y a representarlos gráficamente.

¿Qué es un algoritmo?

Un algoritmo es un conjunto finito, ordenado y bien definido de instrucciones o pasos que permiten resolver un problema o realizar una tarea. Ejemplos cotidianos:

  • Receta de cocina: Lista ordenada de pasos para preparar un plato.
  • Montaje de muebles: Instrucciones paso a paso de IKEA.
  • GPS: Instrucciones de navegación desde origen hasta destino.
  • Protocolo médico: Secuencia de pasos para realizar un diagnóstico.

Características de un buen algoritmo

  • Finite (finito): Debe terminar en algún momento.
  • Preciso: Cada paso debe estar claramente definido.
  • Bien definido: No debe haber ambigüedades.
  • Con entrada: Recibe datos iniciales.
  • Con salida: Produce un resultado.
Pseudocódigo El pseudocódigo es una representación textual de un algoritmo que usa lenguaje natural combinado con estructuras de programación. No es código ejecutable, pero ayuda a planificar la solución antes de escribir código real.

Diagramas de flujo

Un diagrama de flujo es la representación gráfica de un algoritmo. Utiliza figuras con significados específicos:

  • Óvalo (Terminal): Inicio y fin del algoritmo.
  • Paralelogramo (Entrada/Salida): Leer datos o mostrar resultados.
  • Rectángulo (Proceso): Operación, cálculo o asignación.
  • Diamante (Decisión): Pregunta con respuesta sí/no. Conduce a dos caminos diferentes.
  • Flechas (Flujo): Conectan las figuras mostrando el orden de ejecución.

Ejemplo: Algoritmo para calcular el área de un rectángulo

INICIO
  Leer base
  Leer altura
  area ← base × altura
  Mostrar area
FIN

De los bloques al código. Transición de programación visual a textual

Introducción

Muchos alumnos han utilizado herramientas de programación visual como Scratch, Blockly o App Inventor. En esta sesión haremos la transición de estos bloques visuales al código textual en Python, demostrando que la lógica es la misma, solo cambia la sintaxis.

Programación visual vs. textual

  • Bloques (Scratch): Arrastrar y soltar piezas de código. No hay errores de sintaxis. Visual e intuitivo.
  • Código textual (Python): Escribir líneas de código con teclado. Requiere sintaxis correcta. Más potente y flexible.
  • La lógica es la misma: Secuencia, decisión (si...entonces), repetición (mientras...), variables, funciones.

Por qué Python

Python es el lenguaje ideal para comenzar a programar:

  • Sintaxis simple y legible: Se parece al pseudocódigo y al inglés.
  • Amplia comunidad: Miles de tutoriales, foros y recursos gratuitos.
  • Múltiples aplicaciones: Web, ciencia de datos, inteligencia artificial, automatización.
  • Alto nivel: El programador se enfoca en la lógica, no en detalles del hardware.
  • Uso educativo: Utilizado en la mayoría de cursos introductorios a la programación.
Ejemplo: Scratch vs. Python En Scratch: bloque "decir Hola mundo". En Python: print("Hola mundo"). La lógica es idéntica: ejecutar una acción que muestra un mensaje.

Entorno de desarrollo

Para escribir y ejecutar código Python necesitamos:

  • Intérprete Python: El programa que ejecuta el código.
  • IDLE: Entorno incluido con Python. Sencillo para empezar.
  • Visual Studio Code: Editor potente con extensiones para Python.
  • Google Colab: Entorno online de Python (no necesita instalación).
  • Replit: Entorno online con Python preinstalado.

Tipos de datos y variables. int, float, str, bool. Constantes, operadores, expresiones

Introducción

Las variables son los contenedores de datos de un programa. Entender los tipos de datos, las variables, las constantes y los operadores es fundamental para escribir código funcional. En esta sesión aprenderemos a almacenar y manipular datos en Python.

¿Qué es una variable?

Una variable es un espacio en la memoria del ordenador donde se almacena un dato. Tiene un nombre, un tipo y un valor:

nombre = "Ana"          # str (cadena de texto)
edad = 16               # int (entero)
altura = 1.65           # float (decimal)
es_mayor = True         # bool (booleano)

Tipos de datos básicos

  • int (entero): Números sin decimales. Ej: 42, -7, 0, 1000000.
  • float (decimal): Números con punto decimal. Ej: 3.14, -0.5, 2.0.
  • str (string/cadena): Texto entre comillas. Ej: "Hola", 'Python', "123".
  • bool (booleano): Verdadero o falso. Ej: True, False.

Verificar tipo: type(variable)

Convenciones de nombres En Python: los nombres de variables empiezan por minúscula, usan guión bajo (_) para separar palabras (edad_alumno), no pueden empezar por número, no pueden ser palabras reservadas (if, for, while, print...).

Asignación de valores

# Asignación simple
nombre = "Carlos"

# Asignación múltiple
x, y, z = 10, 20, 30

# Intercambio de valores
a, b = 5, 10
a, b = b, a   # Ahora a=10, b=5

# Asignación con operación
edad = 2026 - 2010   # edad = 16

Constantes

En Python no hay constantes técnicas (el lenguaje no lo impide), pero por convención se usan nombres en MAYÚSCULAS:

PI = 3.14159
IMPUESTO = 0.21
MAX IntentOS = 3

Operadores

  • Aritméticos: + (suma), - (resta), * (multiplicación), / (división), // (división entera), % (módulo), ** (potencia).
  • Comparación: == (igual), != (diferente), > (mayor), < (menor), >= (mayor o igual), <= (menor o igual).
  • Lógicos: and (Y), or (O), not (NO).
  • Asignación: =, +=, -=, *=, /=.

Expresiones

Una expresión es combinación de valores, variables y operadores que se evalúa para producir un resultado:

radio = 5
area = PI * radio ** 2   # Expresión: 3.14159 × 25 = 78.54

temperatura_c = 25
temperatura_f = temperatura_c * 9 / 5 + 32  # 77.0

es_positivo = (area > 0) and (temperatura_c > 0)  # True

Interacción con el usuario. print(), input(), conversión de tipos

Introducción

Un programa interactivo se comunica con el usuario: le pide datos, procesa información y muestra resultados. Las funciones print() e input() son las bases de esta interacción. En esta sesión profundizaremos en su uso y aprenderemos a manejar la conversión entre tipos de datos.

La función print()

Muestra información por pantalla. Puede recibir múltiples argumentos:

# Impresión básica
print("Hola mundo")

# Múltiples argumentos (se separan por espacio)
print("Nombre:", "Ana", "Edad:", 16)

# Cambiar el separador
print("Python", "es", "genial", sep="-")

# Final de línea (por defecto es \n)
print("Hola", end=" ")
print("mundo")  # Salida: Hola mundo (en la misma línea)

# Impresión con formato (f-strings)
nombre = "Ana"
edad = 16
print(f"Me llamo {nombre} y tengo {edad} años")

La función input()

Pide al usuario que introduzca datos por teclado. Siempre devuelve una cadena de texto (str):

# Input básico
nombre = input("¿Cómo te llamas? ")
print(f"Hola, {nombre}")

# Input con mensaje
edad = input("¿Cuántos años tienes? ")
# Nota: edad es un string, no un número
¡Importante! input() SIEMPRE devuelve un string. Si necesitas un número, debes convertirlo explícitamente con int() o float(). Si el usuario escribe "abc" cuando esperabas un número, obtendrás un error ValueError.

Conversión de tipos (casting)

# String → Entero
edad = int(input("Edad: "))

# String → Decimal
altura = float(input("Altura: "))

# Número → String
precio = 19.99
print("El precio es: " + str(precio))

# Verificar tipo
print(type(edad))   # <class 'int'>
print(type(altura)) # <class 'float'>

Formato de salida avanzado

# F-strings (Python 3.6+) — la forma moderna
nombre = "Ana"
nota = 8.5
print(f"Alumna: {nombre}, Nota: {nota:.1f}")

# Métodos de formato
precio = 1234.56
print(f"Precio: {precio:,.2f} €")  # 1,234.56 €

# Alineación
for i in range(1, 6):
    print(f"Ejercicio {i:2d}: Nota {i*1.5:.1f}")

Estructuras de control. Condicionales (if/elif/else). Bucles (for con range(), while)

Introducción

Las estructuras de control permiten que un programa tome decisiones y repita acciones. Sin ellas, los programas serían una secuencia lineal de instrucciones. En esta sesión estudiaremos las estructuras condicionales y los bucles, los dos pilares de la lógica de programación.

Condicionales: if / elif / else

Permiten ejecutar código solo si se cumple una condición:

# Estructura básica
nota = float(input("Introduce tu nota: "))

if nota >= 9:
    print("Sobresaliente")
elif nota >= 7:
    print("Notable")
elif nota >= 5:
    print("Aprobado")
else:
    print("Suspenso")

Regla clave: La indentación (4 espacios) define el bloque de código que se ejecuta. Python usa sangría en lugar de llaves {}.

Importante: elif vs. else elif permite evaluar múltiples condiciones en secuencia. else captura el caso por defecto (si ninguna condición se cumple). El orden importa: las condiciones se evalúan de arriba a abajo.

Bucle for

Repite un bloque de código un número determinado de veces:

# For con range()
for i in range(5):        # 0, 1, 2, 3, 4
    print(i)

for i in range(1, 11):    # 1 al 10
    print(f"Tabla del 2: 2 × {i} = {2*i}")

# For con lista
frutas = ["manzana", "plátano", "naranja"]
for fruta in frutas:
    print(f"Me gusta la {fruta}")

Bucle while

Repite mientras se cumpla una condición:

# Contador
contador = 0
while contador < 5:
    print(f"Contador: {contador}")
    contador += 1

# Validación de entrada
while True:
    nota = float(input("Nota (0-10): "))
    if 0 <= nota <= 10:
        break   # Sale del bucle
    print("Error: introduce un valor entre 0 y 10")
Bucles infinitos Un while True sin break es un bucle infinito que nunca termina. Siempre asegúrate de tener una condición de salida o usa break para salir del bucle.

Estructuras de datos. Listas, tuplas, diccionarios

Introducción

Las estructuras de datos permiten almacenar múltiples valores en una sola variable. En esta sesión estudiaremos las tres estructuras principales de Python: listas (mutables), tuplas (inmutables) y diccionarios (pares clave-valor).

Listas (lists)

Colecciones ordenadas y mutables de elementos:

# Crear una lista
notas = [8, 7, 9, 6, 10]
nombres = ["Ana", "Carlos", "María"]
mezcla = [1, "hola", 3.14, True]  # Tipos mixtos

# Acceder por índice (empieza en 0)
print(nombres[0])      # Ana
print(nombres[-1])     # María (último)

# Modificar
notas[0] = 9           # Cambia el primer elemento

# Métodos útiles
notas.append(7)        # Añadir al final
notas.remove(8)        # Eliminar el primer 8
notas.insert(1, 5)     # Insertar 5 en la posición 1
notas.pop()            # Eliminar y devolver el último
len(notas)             # Longitud de la lista
sum(notas)             # Suma de todos los elementos
notas.sort()           # Ordenar de menor a mayor
Lista vacía Para crear una lista vacía: lista = [] o lista = list(). Es útil para ir añadiendo elementos dinámicamente.

Tuplas (tuples)

Colecciones ordenadas e inmutables. No se pueden modificar después de crearlas:

# Crear una tupla
coordenadas = (40.4168, -3.7038)
colores = ("rojo", "verde", "azul")

# Acceder (igual que las listas)
print(coordenadas[0])   # 40.4168

# Las tuplas NO se pueden modificar
# coordenadas[0] = 50   # ¡Error! TypeError

# Desempaquetar
lat, lon = coordenadas
print(f"Latitud: {lat}, Longitud: {lon}")

Diccionarios (dict)

Colecciones de pares clave:valor. No tienen orden definido (en versiones antiguas de Python):

# Crear un diccionario
alumno = {
    "nombre": "Ana",
    "edad": 16,
    "nota_media": 8.5,
    "aprobado": True
}

# Acceder por clave
print(alumno["nombre"])        # Ana
print(alumno.get("email", "No disponible"))  # Valor por defecto

# Modificar
alumno["edad"] = 17
alumno["email"] = "ana@email.com"

# Métodos útiles
alumno.keys()       # Todas las claves
alumno.values()     # Todos los valores
alumno.items()      # Todos los pares clave-valor

# Eliminar
del alumno["email"]
¿Cuándo usar cada uno? Lista: Colección de elementos del mismo tipo que puede cambiar. Tupla: Datos fijos que no deben modificarse (coordenadas, fechas). Diccionario: Datos con significado semántico (perfil de usuario, registro de base de datos).

Funciones. Definición, parámetros, retorno. Modularización de código

Introducción

Las funciones permiten organizar el código en bloques reutilizables. En lugar de escribir el mismo código varias veces, lo encapsulamos en una función que podemos llamar cuantas veces necesitemos. Las funciones son la base de la programación modular y el código limpio.

¿Qué es una función?

Una función es un bloque de código con un nombre que realiza una tarea específica:

# Definición de función
def saludar(nombre):
    """Saluda a una persona."""
    print(f"¡Hola, {nombre}! Bienvenido.")

# Llamada a la función
saludar("Ana")      # ¡Hola, Ana! Bienvenido.
saludar("Carlos")   # ¡Hola, Carlos! Bienvenido.

Parámetros y argumentos

  • Parámetro: Variable en la definición de la función.
  • Argumento: Valor real que se pasa al llamar a la función.
  • Parámetros por defecto: Valor que toma el parámetro si no se proporciona.
  • Parámetros posicionales: Se asignan por orden.
  • Parámetros con nombre (keyword): Se asignan por nombre.
# Parámetro por defecto
def calcularnota(examen, trabajo=0.3):
    return examen * (1 - trabajo) + trabajo * 10

# Llamadas
print(calcularnota(8))              # Usando valor por defecto
print(calcularnota(8, 0.4))         # Valor explícito
print(calcularnota(trabajo=0.4, examen=8))  # Con nombre

Retorno de valores

# Función con return
def calcular_area(base, altura):
    """Calcula el área de un rectángulo."""
    return base * altura

area = calcular_area(5, 3)
print(f"Área: {area}")  # Área: 15

# Múltiples valores de retorno
def min_max(lista):
    return min(lista), max(lista)

minimo, maximo = min_max([3, 1, 4, 1, 5, 9])
print(f"Mín: {minimo}, Máx: {maximo}")  # Mín: 1, Máx: 9
Docstrings El docstring (cadena de texto triple entre comillas) documenta qué hace la función. Se accede con help(funcion) o funcion.__doc__. Es una buena práctica incluirlo siempre.

Alcance de variables

  • Variable local: Existe solo dentro de la función.
  • Variable global: Existe en todo el programa. Se puede acceder desde cualquier función, pero es mejor evitar modificarlas.

Depuración. Errores comunes, depuración paso a paso

Introducción

Todo programador se encuentra con errores. Depurar es el proceso de encontrar y corregir errores en el código. Es una habilidad tan importante como escribir código. En esta sesión aprenderemos a identificar los tipos de errores más comunes y a usar técnicas de depuración.

Tipos de errores

  • Errores de sintaxis (SyntaxError): El código no sigue las reglas del lenguaje. Ejemplo: print("Hola" (falta paréntesis de cierre).
  • Errores en tiempo de ejecución (Exceptions): El código tiene sintaxis correcta pero falla al ejecutarse. Ejemplo: división por cero, variable no definida.
  • Errores lógicos: El programa funciona pero produce un resultado incorrecto. Ejemplo: usar + en lugar de * en un cálculo.
Los errores más comunes en principiantes 1. Olvidar los dos puntos (:) después de if, for, while, def. 2. Error de indentación (mezclar espacios y tabulaciones). 3. Usar = en lugar de == en condiciones. 4. Olvidar convertir el resultado de input() a número.

Excepciones comunes

  • TypeError: Operación con tipos incompatibles. Ej: "hola" + 5.
  • ValueError: Valor incorrecto. Ej: int("abc").
  • NameError: Variable no definida. Ej: print(variable_inexistente).
  • IndexError: Índice fuera de rango. Ej: lista[100] con 5 elementos.
  • KeyError: Clave no encontrada en diccionario.
  • ZeroDivisionError: División por cero.
  • FileNotFoundError: Archivo no encontrado.

Técnicas de depuración

  • Print de depuración: Añadir print() para ver el valor de variables en puntos clave.
  • Depurador paso a paso: Ejecutar el código línea por línea (pdb en Python, depurador de VS Code).
  • Método de mitad: Añadir un print a mitad del programa para ver si el error está antes o después.
  • Leer el traceback: Python muestra información detallada del error: tipo, línea y mensaje.

Manejo de errores con try/except

# Manejo de excepciones
try:
    nota = float(input("Introduce tu nota: "))
    resultado = 10 / nota
    print(f"Resultado: {resultado}")
except ValueError:
    print("Error: Debes introducir un número.")
except ZeroDivisionError:
    print("Error: No se puede dividir por cero.")
except Exception as e:
    print(f"Error inesperado: {e}")
finally:
    print("Este código se ejecuta siempre.")
Consejo práctico Cuando tu código no funciona: 1) Lee el mensaje de error completo. 2) Identifica la línea exacta. 3) Comprueba la sintaxis de esa línea. 4) Añade print() para ver los valores de las variables. 5) Si no encuentras el error, pide a alguien que lea tu código con otros ojos.

Proyecto final: programa completo que integre todos los conceptos

Proyecto de unidad Esta sesión está dedicada al desarrollo del proyecto final de la UD6 y de toda la asignatura. Cada alumno deberá crear un programa completo en Python que integre todos los conceptos trabajados a lo largo de las 8 sesiones anteriores.

Enunciado del proyecto

Crear un "Sistema de Gestión de Calificaciones" que permita:

  • Menú principal: Opciones para añadir alumnos, introducir notas, ver estadísticas, listar alumnos y salir.
  • Añadir alumnos: Pide nombre y almacena en una lista de diccionarios.
  • Introducir notas: Permite asignar notas a un alumno específico.
  • Ver estadísticas: Media general, nota máxima, nota mínima, número de aprobados/suspensos.
  • Listar alumnos: Muestra todos los alumnos con sus notas y media.
  • Funciones: Cada operación debe ser una función independiente.
  • Validación: Manejar errores de entrada con try/except.
  • Estructuras de datos: Usar listas de diccionarios.
Criterios de evaluación Funcionamiento correcto (30%), uso de funciones (20%), estructuras de datos (15%), manejo de errores (15%), calidad del código y comentarios (10%), interfaz de usuario (10%).
