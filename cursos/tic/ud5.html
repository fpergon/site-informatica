Hardware y software. Sistemas propietarios y libres. Clasificaciones

Nota didáctica Esta sesión inicial sitúa las bases conceptuales de la unidad: la distinción entre hardware y software, y la diferencia entre sistemas propietarios y libres. Estos conceptos son fundamentales para entender el resto de la unidad.

Introducción

Todo sistema informático se compone de dos partes fundamentales: el hardware (componentes físicos) y el software (programas que los hacen funcionar). En esta sesión exploraremos ambas dimensiones y conoceremos las diferentes filosofías de desarrollo de software.

Hardware vs. Software

  • Hardware: Componentes físicos y tangibles del ordenador. Se puede tocar: placa base, procesador, memoria RAM, disco duro, monitor, teclado, ratón.
  • Software: Conjunto de programas e instrucciones que permiten realizar tareas. Es intangible: sistemas operativos, aplicaciones, controladores, utilidades.

Relación: El hardware sin software es inútil (un teléfono sin sistema operativo no sirve). El software sin hardware es imposible ejecutarse (un juego necesita un ordenador para funcionar).

Clasificación del hardware

  • Unidad Central de Procesamiento (CPU): El "cerebro" del ordenador. Procesa instrucciones y ejecuta cálculos.
  • Memoria: Almacena datos temporalmente (RAM) o permanentemente (ROM, disco).
  • Almacenamiento: Disco duro (HDD), unidad de estado sólido (SSD), tarjetas SD, discos externos.
  • Periféricos: Dispositivos de entrada (teclado, ratón, micrófono) y salida (monitor, altavoces, impresora).
  • Placa base: Componente que conecta todos los demás elementos.
  • Fuente de alimentación: Proporciona energía eléctrica al sistema.
Clasificación por tamaño Supercomputadoras: Miles de procesadores, cálculos científicos. Mainframes: Empresas grandes, alta capacidad de procesamiento. Minicomputadoras: Servidores medianos. Microcomputadoras: PC, portátiles, tablets. Smartphones: Dispositivos móviles.

Software propietario vs. software libre

  • Software propietario: Código fuente cerrado. No se puede copiar, modificar ni redistribuir. Licencia de uso. Ejemplos: Windows, macOS, Microsoft Office.
  • Software libre (free software): Código fuente abierto. Cualquiera puede usar, estudiar, modificar y distribuir. Licencias como GPL, MIT, Apache. Ejemplos: Linux, LibreOffice, GIMP, Firefox.
  • Software freeware: Gratuito pero con código cerrado. No se puede modificar. Ejemplos: Skype, Adobe Reader.
  • Software shareware: Versión de prueba gratuita con limitaciones. Hay que pagar para desbloquear todas las funciones.
Las 4 libertades del software libre 1. Libertad de usar el programa con cualquier propósito. 2. Libertad de estudiar cómo funciona y modificarlo. 3. Libertad de redistribuir copias. 4. Libertad de distribuir copias de versiones modificadas.

Arquitectura clásica. CPU, UAL, UC. Ley de Moore

Introducción

La arquitectura de von Neumann es el diseño fundamental de los ordenadores modernos. Todos los sistemas informáticos actuales, desde un smartphone hasta un supercomputador, se basan en esta arquitectura. En esta sesión estudiaremos sus componentes principales y la ley que ha impulsado su evolución.

Arquitectura de von Neumann

Propuesta por John von Neumann en 1945, establece que un ordenador se compone de:

  • Unidad Central de Procesamiento (CPU): Procesa las instrucciones.
  • Memoria: Almacena datos e instrucciones.
  • Entrada/Salida: Dispositivos para interactuar con el exterior.
  • Bus de datos: Canal por el que fluyen los datos entre componentes.

Principio clave: Programas y datos se almacenan en la misma memoria. La CPU lee instrucciones de memoria, las decodifica y las ejecuta secuencialmente.

Diagrama simplificado Memoria ←→ CPU (UAL + UC) ←→ E/S. La CPU se comunica con la memoria a través del bus de direcciones y datos, y con los dispositivos de entrada/salida a través del bus de control.

Componentes de la CPU

  • Unidad de Control (UC): Lee, decodifica y coordina la ejecución de instrucciones. Dirige el flujo de datos entre la CPU, la memoria y los dispositivos.
  • Unidad Aritmético-Lógica (UAL): Realiza operaciones aritméticas (suma, resta, multiplicación) y lógicas (AND, OR, comparaciones).
  • Registros: Pequeñas memorias ultra-rápidas dentro de la CPU para almacenar datos temporales.
  • Caché: Memoria de alta velocidad que almacena datos frecuentemente usados para acelerar el acceso.

El ciclo de ejecución

Cada instrucción sigue este ciclo:

  1. Fetch (Obtener): La UC lee la siguiente instrucción de la memoria.
  2. Decode (Decodificar): La UC interpreta qué operación debe realizarse.
  3. Execute (Ejecutar): La UAL ejecuta la operación (cálculo, comparación).
  4. Store (Almacenar): El resultado se guarda en un registro o en la memoria.

Ley de Moore

Enunciada por Gordon Moore en 1965, establece que el número de transistores en un microprocesador se duplica aproximadamente cada 2 años, lo que implica un aumento exponencial de la potencia de cálculo:

  • 1971 (Intel 4004): 2.300 transistores.
  • 1990 (Intel 486): 1,2 millones de transistores.
  • 2000 (Pentium 4): 42 millones de transistores.
  • 2020 (Apple M1): 16.000 millones de transistores.
  • 2024: Los procesadores más avanzados superan los 100.000 millones de transistores.
Límites de la ley de Moore La ley de Moore no es una ley física, sino una observación empírica. Se ha mantenido durante décadas, pero ahora enfrenta límites físicos: el tamaño de los transistores se acerca al límite atómico, y el calor generado es cada vez más difícil de disipar.

Memoria y almacenamiento. Memoria principal, almacenamiento secundario. Estructura física y lógica

Introducción

La memoria y el almacenamiento son componentes esenciales de cualquier sistema informático. Aunque a menudo se confunden, son conceptos muy diferentes en cuanto a velocidad, capacidad y función. En esta sesión estudiaremos las diferencias y el funcionamiento de cada tipo.

Memoria principal (RAM)

La RAM (Random Access Memory) es la memoria de trabajo del ordenador. Almacena temporalmente los datos e instrucciones que la CPU está utilizando activamente:

  • Volátil: Se borra al apagar el ordenador.
  • Rápida: Tiempo de acceso de nanosegundos.
  • Capacidad: Los ordenadores actuales tienen entre 8 GB y 64 GB.
  • Tipos: DDR4 (actual), DDR5 (nueva generación), GDDR (para tarjetas gráficas).

Memoria ROM

La ROM (Read-Only Memory) almacena datos permanentes que no se pueden modificar:

  • No volátil: Mantiene los datos sin energía.
  • Contiene: El firmware (BIOS/UEFI) que inicia el ordenador.
  • Tipos: PROM, EPROM, EEPROM, Flash ROM.
RAM vs. Almacenamiento La RAM es como la memoria a corto plazo del cerebro: rápida pero temporal. El almacenamiento es como la memoria a largo plazo: más lento pero permanente. Un programa se carga del disco a la RAM para ejecutarse.

Almacenamiento secundario

  • HDD (Hard Disk Drive): Disco mecánico con platos giratorios y cabezales de lectura/escritura. Alta capacidad (hasta 20 TB), bajo coste, más lento.
  • SSD (Solid State Drive): Almacenamiento electrónico sin partes móviles. Mucho más rápido, silencioso, resistente a golpes. Menor capacidad por euro.
  • NVMe: SSD de alta velocidad que se conecta directamente al bus PCIe. Velocidades de lectura/escritura de hasta 7.000 MB/s.
  • Almacenamiento externo: Discos portátiles USB, tarjetas SD, memorias USB.
  • Almacenamiento en la nube: Google Drive, OneDrive, Dropbox. Acceso desde cualquier dispositivo.

Jerarquía de memoria

Los sistemas informáticos organizan la memoria en una jerarquía de velocidad y capacidad:

  1. Registros de la CPU: La más rápida y pequeña.
  2. Caché L1/L2/L3: Memoria ultra-rápida dentro de la CPU.
  3. RAM: Memoria principal, rápida pero volátil.
  4. SSD/NVMe: Almacenamiento rápido, no volátil.
  5. HDD: Almacenamiento lento pero de gran capacidad.
  6. Nube: Acceso remoto, velocidad depende de la conexión.
Consejo práctico Si tu ordenador va lento, la primera mejora más efectiva es cambiar un HDD por un SSD. El tiempo de arranque y la aplicación de programas mejora drásticamente.

Sistemas de entrada/salida. Periféricos. Clasificación. Periféricos de nueva generación

Introducción

Los periféricos son los dispositivos que permiten la interacción entre el usuario y el ordenador. Sin ellos, sería imposible introducir datos o visualizar resultados. En esta sesión estudiaremos su clasificación, funcionamiento y los dispositivos más innovadores.

Periféricos de entrada

Envían datos al ordenador:

  • Teclado: Dispositivo de entrada alfanumérico más utilizado.
  • Ratón/Touchpad: Dispositivo apuntador para seleccionar y manipular elementos en pantalla.
  • Micrófono: Captura de audio para voz, música, videollamadas.
  • Cámara web: Captura de vídeo en tiempo real.
  • Escáner: Digitaliza documentos e imágenes impresas.
  • Lector de código de barras: Lee códigos de productos.
  • Teclado Braille: Permite a personas ciegas escribir texto.

Periféricos de salida

Reciben datos del ordenador:

  • Monitor: Dispositivo de visualización principal.
  • Impresora: Imprime documentos en papel.
  • Altavoces/Auriculares: Reproducen audio.
  • Proyector: Proyecta la imagen en una pantalla grande.

Periféricos de entrada/salida (E/S)

Combinan ambas funciones:

  • Monitor táctil (touchscreen): Muestra información y permite interactuar tocando la pantalla.
  • Memoria USB: Almacena datos y permite su transferencia.
  • Tarjeta de red: Envía y recibe datos a través de la red.
  • Adaptador Bluetooth: Comunicación inalámbrica bidireccional.
  • Consola de videojuegos: Recibe input del mando y genera output de vídeo/audio.
Periféricos de nueva generación Sensores biométricos: Reconocimiento de huella dactilar, facial o de iris. Dispositivos de realidad virtual: Gafas VR con seguimiento de movimiento. Dispositivos de realidad aumentada: Lentes AR que superponen información digital. Wearables: Smartwatches, pulseras de actividad. Drones: Vehículos aéreos no tripulados con cámaras.

Clasificación por conexión

  • Cableados: USB, HDMI, DisplayPort, Thunderbolt, Ethernet.
  • Inalámbricos: Bluetooth, Wi-Fi, NFC, Infrarrojos, Radiofrecuencia.

Buses de comunicación. Datos, control y direcciones

Introducción

Los buses son los canales de comunicación por los que viajan los datos entre los componentes de un ordenador. Son como las autopistas del sistema informático: cuantos más carriles tienen y a mayor velocidad, mejor es el rendimiento del equipo.

¿Qué es un bus?

Un bus es un conjunto de líneas de comunicación (cables o pistas en la placa base) que permiten la transmisión de información entre componentes. Se clasifican en tres tipos:

  • Bus de datos: Transporta los datos propiamente dichos. Su anchura (número de líneas) determina cuántos bits se transfieren simultáneamente.
  • Bus de direcciones: Indica dónde están los datos de origen y destino (direcciones de memoria o dispositivos).
  • Bus de control: Emite señales de sincronización, petición, lectura/escritura y confirmación.
Analogía Piensa en una oficina de correos: el bus de datos son las cartas, el bus de direcciones es la dirección del remitente y destinatario, y el bus de control es el empleado que gestiona el envío y confirmación de recepción.

Tipos de buses según su alcance

  • Bus interno: Conecta los componentes dentro de la CPU o entre CPU y memoria. Es el más rápido.
  • Bus del sistema: Conecta la CPU con la memoria principal y los dispositivos de la placa base.
  • Bus externo: Conecta periféricos externos (USB, Thunderbolt, HDMI).

Buses comunes

  • USB (Universal Serial Bus): El bus más utilizado para periféricos. Versiones: USB 2.0 (480 Mbps), USB 3.0 (5 Gbps), USB 3.2 (20 Gbps), USB4 (40 Gbps).
  • PCIe (Peripheral Component Interconnect Express): Bus de alta velocidad para componentes internos (tarjetas gráficas, SSD NVMe). PCIe 5.0: 64 GB/s.
  • SATA: Para discos duros y SSD. SATA III: 6 Gbps.
  • Ethernet: Para redes cableadas. 1 Gbps, 10 Gbps.
  • Thunderbolt: Combina datos, vídeo y energía en un solo puerto. Thunderbolt 4: 40 Gbps.

Rendimiento de los buses

El rendimiento de un bus depende de:

  • Anchura de banda: Número de bits que se transfieren en paralelo.
  • Frecuencia: Número de transferencias por segundo.
  • Protocolo: Reglas de comunicación que optimizan la transmisión.

Fórmula: Rendimiento = Anchura × Frecuencia × Número de ciclos.

Evolución Los buses han evolucionado de paralelos (ISA, PCI) a seriales (USB, PCIe). Paradójicamente, los seriales modernos son mucho más rápidos porque permiten mayores frecuencias y menos interferencias.

Sistemas operativos. Arquitecturas, funciones, licencias, interfaces de usuario

Introducción

El sistema operativo (SO) es el software más importante de un ordenador. Actúa como intermediario entre el usuario y el hardware, gestionando todos los recursos del sistema. Sin un SO, el hardware sería inutilizable. En esta sesión estudiaremos las funciones, tipos e interfaces de los sistemas operativos.

¿Qué es un sistema operativo?

Un sistema operativo es el conjunto de programas que gestiona los recursos hardware y software del ordenador, proporcionando servicios a las aplicaciones y una interfaz al usuario:

  • Gestión de procesos: Planifica qué procesos se ejecutan y en qué orden.
  • Gestión de memoria: Asigna y libera memoria RAM a los procesos.
  • Gestión de archivos: Organiza, almacena y recupera archivos en el almacenamiento.
  • Gestión de dispositivos: Controla periféricos mediante controladores (drivers).
  • Seguridad: Control de acceso, autenticación de usuarios, protección contra malware.
  • Interfaz de usuario: Proporciona una forma de interactuar con el sistema.
Tipos de interfaces CLI (Command Line Interface): Interfaz de línea de comandos. El usuario escribe comandos de texto. Ejemplo: Terminal de Linux, CMD de Windows. Es rápida y potente pero requiere conocimientos. GUI (Graphical User Interface): Interfaz gráfica con ventanas, iconos y menús. Es intuitiva pero más lenta de ejecutar.

Principales sistemas operativos

  • Windows: El más usado en PC de escritorio. Propietario, interfaz gráfica, amplia compatibilidad de hardware.
  • macOS: Sistema de Apple para Mac. Propietario, optimizado para hardware Apple, interfaz pulida.
  • Linux: Kernel de código abierto. Múltiples distribuciones: Ubuntu, Fedora, Debian, Arch. Gratuito, seguro, personalizable.
  • Android: Basado en Linux, para dispositivos móviles. Desarrollado por Google.
  • iOS: Sistema de Apple para iPhone/iPad. Propietario, optimizado para hardware Apple.
  • ChromeOS: Sistema de Google basado en navegador web. Ligero, para Chromebooks.

Licencias de software

  • Propietaria: El código fuente no está disponible. Pago por licencia. Ejemplo: Windows.
  • Open Source: Código abierto, cualquier persona puede modificarlo. Ejemplo: Linux (GPL).
  • Freeware: Gratuito pero con código cerrado. Ejemplo: Skype.
  • Shareware: Versión de prueba con limitaciones temporales.

Gestión del SO. Procesos, archivos, usuarios, dispositivos. Instalación y configuración

Proyecto de unidad Esta sesión integra todo lo aprendido sobre arquitectura y sistemas operativos. El alumnado aplicará los conocimientos teóricos en un ejercicio práctico de gestión del sistema.

Gestión de procesos

Un proceso es un programa en ejecución. El SO gestiona múltiples procesos simultáneamente mediante la planificación:

  • Estado de un proceso: Nuevo, listo, ejecutando, esperando, terminado.
  • Planificación: El SO decide qué proceso se ejecuta en cada momento (round-robin, prioridades).
  • Multitarea: El SO alterna rápidamente entre procesos, dando la ilusión de ejecución simultánea.
  • Administrador de tareas: Herramienta para ver y finalizar procesos (Ctrl+Alt+Supr en Windows, htop en Linux).

Gestión de archivos

  • Sistema de archivos: NTFS (Windows), APFS (macOS), ext4 (Linux), FAT32, exFAT.
  • Estructura de carpetas: Árbol jerárquico de directorios.
  • Permisos: Lectura, escritura, ejecución. Para propietario, grupo y otros.
  • Respaldo: Copias de seguridad regulares. Tipos: completa, incremental, diferencial.

Gestión de usuarios

  • Usuarios: Cada persona tiene su propia cuenta con permisos específicos.
  • Administrador: Usuario con permisos totales para configurar el sistema.
  • Grupo: Conjunto de usuarios con los mismos permisos.
  • Autenticación: Contraseña, biométrica, doble factor (2FA).

Gestión de dispositivos

  • Controladores (drivers): Software que permite al SO comunicarse con cada hardware.
  • Device Manager (Windows): Herramienta para administrar dispositivos y controladores.
  • Actualizaciones: Mantener los controladores actualizados para mejor rendimiento y seguridad.
Consejo práctico Si un dispositivo no funciona correctamente, la primera solución suele ser actualizar o reinstalar su controlador desde el administrador de dispositivos.

Instalación de un sistema operativo

  1. Preparar: Verificar requisitos del hardware, hacer copia de seguridad.
  2. Crear medio de instalación: USB booteable con la imagen ISO del SO.
  3. Arrancar desde USB: Configurar el BIOS/UEFI para arrancar desde el USB.
  4. Instalar: Seguir el asistente de instalación (particionar disco, configurar usuario).
  5. Configurar: Instalar controladores, actualizaciones, software adicional.
