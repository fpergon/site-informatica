UD3 · Desarrollo Web

Profundizar en el desarrollo web mediante el análisis de la estructura de las páginas, el funcionamiento de los servidores, los lenguajes HTML/CSS/JavaScript y las técnicas de animación. Esta unidad sentará las bases para crear sitios web interactivos y accesibles.

1

Análisis de estructura web

Nota didáctica Esta sesión inicial sienta las bases teóricas para comprender cómo se organizan y diseñan los sitios web. Es fundamental que el alumnado asimile estos conceptos antes de pasar a la práctica con HTML y CSS.

Introducción

¿Alguna vez os habéis preguntado por qué algunas webs son fáciles de usar y otras resultan confusas? En esta sesión vamos a analizar la estructura subyacente de los sitios web, desde la organización del contenido hasta la jerarquía visual que guía la mirada del usuario. Comenzaremos visitando tres sitios web muy diferentes (una tienda online, un blog de tecnología y la web de un periódico) para identificar patrones comunes y diferencias en su diseño.

Organización del contenido

Un sitio web bien organizado sigue una estructura jerárquica que facilita la navegación. Los elementos fundamentales son:

  • Arquitectura de la información: Cómo se estructuran y categorizan los contenidos. Un buen mapa del sitio permite al usuario encontrar lo que busca en pocos clics.
  • Navegación: El menú principal, los enlaces de pie de página y las migas de pan (breadcrumbs) son los pilares de la navegación web.
  • Consistencia: Los elementos repetidos en todas las páginas (cabecera, pie, colores, tipografía) crean una experiencia coherente.
  • Accesibilidad: El contenido debe ser usable por todas las personas, incluyendo aquellas con discapacidades visuales, motoras o cognitivas. Esto implica usar etiquetas semánticas, contraste suficiente y texto alternativo en imágenes.

Jerarquía visual

La jerarquía visual determina el orden en que el usuario percibe los elementos de la página. Se consigue mediante:

  • Tamaño: Los titulares más grandes atraen la atención primero.
  • Color y contraste: Los elementos con mayor contraste destacan sobre el resto.
  • Espacio en blanco: Un buen uso del margen y el padding dirige la mirada del lector.
  • Tipografía: Combinar distintos pesos y tamaños de fuente para diferenciar títulos, subtítulos y cuerpo de texto.
  • Posición: Los elementos en la parte superior y a la izquierda suelen leerse primero en culturas occidentales.

Interactividad y experiencia de usuario

La interactividad se refiere a todo lo que el usuario puede hacer en una web: hacer clic en botones, rellenar formularios, desplazarse, pasar el cursor por encima de elementos, etc. Una buena experiencia de usuario (UX) implica tiempos de carga rápidos, retroalimentación visual clara (hover, focus) y diseño responsive que se adapte a cualquier tamaño de pantalla.

Importante La accesibilidad web no es opcional. El 15% de la población mundial tiene alguna discapacidad. El diseño accesible beneficia a todos los usuarios, no solo a quienes tienen necesidades específicas.

Tipos de servidores web

Nota didáctica Esta sesión introduce el concepto de servidor web y su funcionamiento. Es clave para que el alumnado comprenda la diferencia entre contenido estático y dinámico, y cómo los servidores entregan las páginas que vemos en el navegador.

Introducción

Cada vez que escribimos una URL en el navegador, se produce una comunicación entre nuestro dispositivo y un servidor web. En esta sesión vamos a entender cómo funciona ese proceso, qué tipos de servidores existen y qué diferencias hay entre servidores estáticos y dinámicos. Este conocimiento es esencial para comprender el desarrollo web completo, no solo el código que escribimos en el cliente.

¿Qué es un servidor web?

Un servidor web es un programa o sistema que almacena y entrega contenido web (páginas HTML, imágenes, archivos CSS, JavaScript, etc.) a los navegadores de los usuarios cuando reciben una solicitud. El protocolo que facilita esta comunicación es HTTP/HTTPS.

El proceso básico es:

  1. El usuario escribe una URL en el navegador.
  2. El navegador envía una solicitud HTTP al servidor.
  3. El servidor procesa la solicitud y responde con el contenido (HTML, CSS, JS, imágenes).
  4. El navegador interpreta el código y renderiza la página en pantalla.

Tipos de servidores por software

  • Apache HTTP Server: El servidor web de código abierto más popular del mundo. Extensible mediante módulos, funciona en prácticamente cualquier sistema operativo. Es el motor detrás de millones de sitios web, incluyendo WordPress.
  • Nginx: Conocido por su alto rendimiento y bajo consumo de recursos. Funciona con un modelo asíncrono de eventos, lo que le permite manejar miles de conexiones simultáneas. Muy usado como proxy inverso y balanceador de carga.
  • Microsoft IIS: Servidor web integrado en Windows Server. Se configura mediante archivos web.config y es la opción natural para entornos con tecnologías Microsoft (ASP.NET).
  • LiteSpeed: Alternativa de alto rendimiento a Apache, compatible con sus configuraciones (.htaccess) pero con menor consumo de memoria.

Servidores estáticos vs. dinámicos

Contenido estático: El servidor entrega archivos tal cual están almacenados (HTML, CSS, JS, imágenes). No hay procesamiento adicional. Es rápido pero inflexible: cada visita ve exactamente lo mismo. Ejemplo: una página de presentación de una empresa.

Contenido dinámico: El servidor ejecuta código (PHP, Python, Node.js, etc.) antes de entregar la respuesta. Puede generar contenido personalizado, interactuar con bases de datos y adaptarse al usuario. Ejemplo: redes sociales, tiendas online, correos electrónicos.

Servidores por propósito

  • Servidores de archivos: Almacenan y comparten archivos en una red (FTP, NAS).
  • Servidores de correo: Gestionan el envío y recepción de correos electrónicos (SMTP, IMAP).
  • Servidores de bases de datos: Almacenan y procesan datos estructurados (MySQL, PostgreSQL, MongoDB).
  • Servidores de aplicaciones: Ejecutan aplicaciones web del lado del servidor (Django, Express, Laravel).
  • Servidores de proxies: Actúan como intermediarios entre el cliente y el servidor original, proporcionando caché, anonimato o filtrado.
Dato real Apache y Nginx juntos alojan más del 60% de todos los sitios web del mundo. Conocer ambos servidores es esencial para cualquier desarrollador web.

Actividad práctica

Vamos a configurar un servidor web local con Apache (o Nginx) en nuestro ordenador:

  1. Instalar Apache usando XAMPP o el gestor de paquetes del sistema.
  2. Crear un archivo index.html en la carpeta de documentos del servidor.
  3. Acceder a http://localhost desde el navegador.
  4. Crear una segunda página y comprobar que se puede acceder a ella añadiendo la ruta.

HTML en profundidad

Nota didáctica En esta sesión profundizamos en HTML más allá de las etiquetas básicas. El dominio de las etiquetas semánticas, los formularios y los atributos esencial es fundamental para crear páginas web accesibles y estructuradas correctamente.

Introducción

HTML (HyperText Markup Language) es el lenguaje de marcado que estructura el contenido de todas las páginas web. En sesiones anteriores ya hemos visto las etiquetas básicas (títulos, párrafos, enlaces, imágenes). Ahora vamos a profundizar en las etiquetas semánticas, los formularios interactivos y los atributos que hacen que HTML sea realmente potente.

Etiquetas semánticas

HTML5 introdujo etiquetas semánticas que dan significado estructural al contenido, mejorando la accesibilidad y el SEO:

  • <header>: Cabecera de la página o de una sección. Contiene títulos, navegación y elementos de identificación.
  • <nav>: Bloque de navegación principal. Contiene los enlaces de menú.
  • <main>: Contenido principal de la página. Solo debe haber uno por página.
  • <section>: Sección temática del contenido. Agrupa contenido relacionado.
  • <article>: Contenido independiente que puede distribuirse (noticia, entrada de blog, tarjeta).
  • <aside>: Contenido complementario (barra lateral, anuncios, enlaces relacionados).
  • <footer>: Pie de página o sección con información de cierre, derechos de autor y enlaces.
  • <figure> y <figcaption>: Para incluir imágenes, diagramas o código con su pie de foto.

Formularios interactivos

Los formularios permiten al usuario enviar datos al servidor. Los elementos más importantes son:

  • <form>: Contenedor principal con atributos action (URL de destino) y method (GET o POST).
  • <input>: Campo de entrada con tipos: text, email, password, number, date, checkbox, radio, file, submit, range, color.
  • <textarea>: Campo de texto multilínea.
  • <select> y <option>: Menú desplegable de selección.
  • <button>: Botón de acción con tipos submit, reset y button.
  • <label>: Etiqueta asociada a un campo, mejora la accesibilidad al vincular el texto con el input.
  • <fieldset> y <legend>: Agrupan campos relacionados dentro de un formulario.
Recuerda Todo campo de formulario debe tener una etiqueta <label> asociada mediante el atributo for. Esto es obligatorio para la accesibilidad y permite que los lectores de pantalla identifiquen cada campo.

Atributos esenciales

  • class / id: Identificadores para CSS y JavaScript.
  • href / src: URLs de destino para enlaces e imágenes.
  • alt: Texto alternativo para imágenes (obligatorio para accesibilidad).
  • title: Texto emergente al pasar el cursor.
  • data-*: Atributos de datos personalizados para JavaScript.
  • required: Indica que un campo de formulario es obligatorio.
  • placeholder: Texto de ejemplo dentro del campo.
  • disabled / readonly: Deshabilita o bloquea un campo.

Actividad práctica

Crear una página web completa de una escuela usando exclusivamente etiquetas semánticas. Debe incluir:

  1. Cabecera con logo y navegación principal.
  2. Sección principal con al menos 3 artículos.
  3. Barra lateral con enlaces relacionados.
  4. Formulario de contacto con validación básica en HTML5.
  5. Pie de página con información de copyright.

CSS en profundidad

Nota didáctica Esta sesión es fundamental para que el alumnado domine las herramientas de diseño visual de la web. CSS es el lenguaje que da estilo y vida a las páginas, y comprender su modelo de cajas, selectores y sistemas de layout es clave para el desarrollo web moderno.

Introducción

CSS (Cascading Style Sheets) es el lenguaje que controla la apariencia visual de las páginas web. Mientras HTML estructura el contenido, CSS define colores, tipografías, espaciados, posiciones y comportamiento visual. En esta sesión profundizaremos en los selectores, el modelo de cajas y los sistemas de layout modernos: Flexbox y Grid.

Selectores CSS

Los selectores determinan a qué elementos HTML se aplican los estilos. Los principales son:

  • Selector de tipo: p { } — Aplica a todos los párrafos.
  • Selector de clase: .card { } — Aplica a todos los elementos con class="card".
  • Selector de ID: #header { } — Aplica solo al elemento con id="header".
  • Selector descendente: nav a { } — Aplica a todos los enlaces dentro de un nav.
  • Selector hijo: ul > li { } — Aplica solo a li directos de ul.
  • Pseudo-clases: :hover, :focus, :nth-child().
  • Pseudo-elementos: ::before, ::after.

Modelo de cajas (Box Model)

Cada elemento HTML es una caja rectangular compuesta por:

  • Content (contenido): El área donde se muestra el texto o la imagen.
  • Padding (relleno): Espacio entre el contenido y el borde.
  • Border (borde): Línea que rodea el padding.
  • Margen (margin): Espacio exterior que separa el elemento de otros.

La propiedad box-sizing: border-box hace que el padding y el border se incluyan dentro del ancho total, simplificando enormemente el diseño.

Flexbox

Flexbox es un sistema de layout unidimensional que facilita la alineación y distribución de elementos dentro de un contenedor. Propiedades principales:

  • display: flex — Activa Flexbox en el contenedor.
  • justify-content — Alineación horizontal (flex-start, center, space-between, space-around).
  • align-items — Alineación vertical (flex-start, center, stretch).
  • flex-direction — Dirección (row, column).
  • flex-wrap — Permite saltos de línea (wrap).
  • gap — Espacio entre elementos.

CSS Grid

Grid es un sistema de layout bidimensional que permite crear estructuras complejas de filas y columnas. Propiedades principales:

  • display: grid — Activa Grid en el contenedor.
  • grid-template-columns — Define las columnas.
  • grid-template-rows — Define las filas.
  • grid-area — Ubica un elemento en el grid.
  • grid-column / grid-row — Ubicación por líneas.
Consejo práctico Usa Flexbox para layouts en una dimensión (una fila o una columna) y Grid para layouts en dos dimensiones (filas y columnas). Ambos se pueden combinar: un contenedor Grid puede contener elementos Flex, y viceversa.

Responsive Design

El diseño responsive hace que las páginas se adapten a diferentes tamaños de pantalla. Las herramientas principales son:

  • Media queries: @media (max-width: 768px) { } — Aplica estilos según el ancho del viewport.
  • Unidades relativas: rem, em, %, vw/vh — Se adaptan al tamaño del contenedor o la ventana.
  • Imágenes fluidas: max-width: 100% — Las imágenes nunca desbordan su contenedor.
  • Viewport meta tag: <meta name="viewport" content="width=device-width">

Actividad práctica

Crear una landing page responsive que combine Flexbox y Grid:

  1. Cabecera con Flexbox (logo a la izquierda, menú a la derecha).
  2. Sección hero con imagen de fondo y texto centrado.
  3. Cuadrícula de 3 tarjetas de servicios con CSS Grid.
  4. Formulario de contacto con Flexbox para alinear campos.
  5. Pie de página con 3 columnas en Grid.
  6. Añadir media queries para que funcione en móvil.

Introducción a JavaScript

Nota didáctica JavaScript es el lenguaje que hace que las páginas web sean interactivas. Esta sesión es la puerta de entrada a la programación del lado del cliente. Es recomendable que el alumnado tenga nociones básicas de lógica (variables, condicionales) antes de esta sesión.

Introducción

HTML da estructura, CSS da estilo, pero JavaScript da vida a una página web. JavaScript permite responder a las acciones del usuario (clics, pulsaciones de teclado, scroll), validar formularios antes de enviarlos, cambiar el contenido de la página sin recargarla y crear animaciones complejas. Es el único lenguaje que se ejecuta directamente en el navegador.

Vídeo recomendado Mira esta introducción a JavaScript para familiarizarte con los conceptos básicos antes de empezar con la práctica:

Manipulación del DOM

El DOM (Document Object Model) es una representación en forma de árbol de todos los elementos de la página. JavaScript puede leer y modificar el DOM en tiempo real:

  • document.getElementById('id') — Selecciona un elemento por su ID.
  • document.querySelector('.clase') — Selecciona el primer elemento que coincide con el selector CSS.
  • document.querySelectorAll('p') — Selecciona todos los elementos que coinciden.
  • element.textContent = 'Nuevo texto' — Cambia el contenido de texto.
  • element.innerHTML = '<h2>Título</h2>' — Cambia el contenido HTML.
  • element.classList.add('activo') — Añade una clase CSS.
  • element.style.color = 'red' — Modifica un estilo directamente.

Eventos

Los eventos son señales que el navegador envía cuando ocurre algo (un clic, una pulsación de tecla, una carga de página). Se gestionan con addEventListener:

  • click — Clic del ratón.
  • keydown / keyup — Pulsación de tecla.
  • submit — Envío de formulario.
  • mouseover / mouseout — Entrada/salida del cursor.
  • load — La página ha terminado de cargar.

Validación de formularios

JavaScript permite validar los datos del usuario antes de enviarlos al servidor. Esto evita errores y mejora la experiencia:

  • Comprobar que los campos obligatorios no están vacíos.
  • Validar que un email tiene un formato correcto.
  • Verificar que las contraseñas coinciden.
  • Mostrar mensajes de error en tiempo real junto al campo correspondiente.

Ejemplo práctico: Crear un formulario de registro que valide nombre, email y contraseña, mostrando mensajes de error en rojo si los datos no son correctos.

Importante La validación con JavaScript es útil para mejorar la experiencia del usuario, pero nunca debe ser la única medida de seguridad. Siempre se debe validar también en el servidor, ya que el usuario puede desactivar JavaScript o modificar el código.

Contenido dinámico

Con JavaScript podemos modificar la página sin recargarla. Ejemplos:

  • Mostrar/ocultar secciones con un botón.
  • Cambiar el tema de la página (modo claro/oscuro).
  • Cargar más contenido al hacer scroll (infinite scroll).
  • Crear un contador de clics en tiempo real.

Actividad práctica

Crear una página interactiva que incluya:

  1. Un botón que cambie el color de fondo de la página.
  2. Un contador que muestre el número de clics realizados.
  3. Un formulario de contacto con validación en tiempo real.
  4. Una sección que se muestre/oculte al hacer clic en un botón.

Animación web

Nota didáctica Las animaciones web añaden dinamismo y mejoran la experiencia de usuario. Esta sesión cubre las principales técnicas de animación disponibles para el desarrollador web, desde transiciones CSS simples hasta animaciones con JavaScript y Canvas.

Introducción

Las animaciones web son cambios visuales que ocurren de forma gradual a lo largo del tiempo. Pueden ser sutiles (un cambio de color al pasar el cursor) o complejas (animaciones de escenas enteras). En esta sesión exploraremos las diferentes técnicas disponibles y sus casos de uso.

CSS Transitions

Las transiciones CSS permiten animar suavemente el cambio de una propiedad de estilo a otra. Son ideales para interacciones simples:

  • transition-property — Qué propiedad se anima (color, transform, opacity).
  • transition-duration — Duración de la transición (0.3s).
  • transition-timing-function — Curva de velocidad (ease, linear, ease-in-out).
  • transition-delay — Retraso antes de iniciar.

Ejemplo: Un botón que cambia de color y tamaño suavemente al pasar el cursor, o una tarjeta que se eleva ligeramente al hacer hover.

CSS Keyframes

Las keyframes permiten crear animaciones más complejas definiendo múltiples estados intermedios:

  • @keyframes — Define la secuencia de la animación.
  • animation-name — Nombre de la animación.
  • animation-duration — Duración total.
  • animation-iteration-count — Número de repeticiones (infinite para bucle).
  • animation-direction — Dirección (normal, alternate).

Ejemplo: Un spinner de carga, una animación de entrada de elementos, o un personaje que camina.

Animaciones con JavaScript

JavaScript ofrece control total sobre las animaciones, permitiendo crear efectos interactivos y dinámicos:

  • requestAnimationFrame() — Ejecuta una función antes del siguiente frame de repintado. Es la forma más eficiente de animar con JS.
  • Animaciones basadas en scroll: Modificar elementos según la posición del usuario al desplazarse.
  • Animaciones interactivas: Que responden al movimiento del ratón o al tacto.
  • Librerías: GSAP, Anime.js, Motion One — Facilitan la creación de animaciones complejas.
Consejo práctico Para animaciones simples (hover, transiciones de color), usa CSS. Para animaciones complejas, interactivas o que requieran control preciso del tiempo, usa JavaScript con requestAnimationFrame. Evita animar propiedades costosas como top, left o width — usa transform y opacity que se ejecutan en la GPU.

SVG y Canvas

SVG (Scalable Vector Graphics): Formato de gráficos vectoriales que se puede animar con CSS o JavaScript. Ideal para iconos, diagramas y gráficos que deben mantener la calidad a cualquier tamaño.

Canvas: Elemento HTML que permite dibujar gráficos像素 a pixels con JavaScript. Ideal para videojuegos, visualizaciones de datos y gráficos complejos que requieren renderizado en tiempo real.

Consideraciones de rendimiento

  • Usa transform y opacity: Estas propiedades se ejecutan en la GPU y son mucho más eficientes que animar position, size o color.
  • Evita reflows: Modificar el layout (width, height, margin) fuerza al navegador a recalcular la posición de todos los elementos.
  • Debounce事件: En eventos como scroll o resize, limita la frecuencia de ejecución de la función de animación.
  • Reduce elementos animados: Cuantos más elementos se animan simultáneamente, mayor es el consumo de recursos.
  • Considera prefers-reduced-motion: Respeta la configuración del usuario que prefiere menos animaciones.

Actividad práctica

Crear una galería de animaciones web que incluya:

  1. Botones con transiciones CSS suaves.
  2. Una animación de carga con @keyframes.
  3. Un efecto parallax al hacer scroll con JavaScript.
  4. Un gráfico SVG animado con CSS.
  5. Un pequeño canvas interactivo que responda al movimiento del ratón.

Proyecto final: sitio web interactivo

Nota didáctica Esta sesión está dedicada a la puesta en común y la presentación de los proyectos finales. Es un momento clave para que el alumnado demuestre lo aprendido y reciba retroalimentación de sus compañeros y el profesor.

Introducción

En esta última sesión de la unidad, cada grupo presentará el sitio web interactivo que ha creado a lo largo de las sesiones anteriores. El proyecto debe integrar todos los conocimientos adquiridos: estructura semántica HTML, estilos con CSS (Flexbox/Grid), interactividad con JavaScript y animaciones. Utilizaremos CodePen como plataforma de desarrollo para facilitar la revisión y la compartición.

Requisitos del proyecto

Cada sitio web interactivo debe cumplir los siguientes requisitos:

  • HTML semántico: Uso correcto de header, nav, main, section, article, footer y formularios con labels.
  • CSS: Uso de Flexbox o Grid para el layout, modelo de cajas correcto y diseño responsive con media queries.
  • JavaScript: Al menos una interacción: validación de formularios, cambio de contenido dinámico o animación.
  • Animaciones: Al menos dos animaciones CSS (transición o keyframe) y una animación con JavaScript.
  • Accesibilidad: Contraste de colores suficiente, texto alternativo en imágenes y etiquetas en formularios.
  • Temática libre: Puede ser una web de una tienda, un blog, un portfolio, una landing page, etc.

Presentación y rúbrica de evaluación

Cada grupo dispondrá de 5 minutos para presentar su proyecto. La evaluación se realizará con la siguiente rúbrica:

  • Funcionalidad (30%): El sitio web funciona correctamente en diferentes navegadores y tamaños de pantalla.
  • Diseño y estética (25%): Uso coherente de colores, tipografía, espaciado y jerarquía visual.
  • Código (25%): HTML semántico, CSS organizado y JavaScript limpio y comentado.
  • Accesibilidad (10%): Cumplimiento de los principios de accesibilidad web.
  • Creatividad (10%): Originalidad del diseño y las interacciones implementadas.
Entrega Cada grupo debe compartir el enlace de su proyecto en CodePen junto con una breve documentación (300-500 palabras) que explique las decisiones de diseño y las tecnologías utilizadas.
