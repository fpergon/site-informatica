Conexión entre lenguajes visuales y textuales: de bloques a código Python

Nota didáctica Esta sesión inicial es fundamental para que los alumnos comprendan que Python no es algo completamente nuevo: es la evolución lógica de lo que ya conocen en Scratch. Partimos de lo que saben para construir sobre ello.

Introducción

En 3º ESO ya habéis programado con bloques visuales en Scratch o App Inventor. Habéis creado juegos, animaciones y quizás incluso apps sencillas. Pero alguna vez os habéis preguntado: ¿cómo funciona realmente el código que escriben los programadores profesionales? En esta sesión vamos a descubrir que la programación textual es simplemente otra forma de expresar las mismas ideas que ya domináis. Python será nuestro primer lenguaje textual, y veréis que muchos conceptos os resultarán familiares desde el primer momento.

Lenguajes visuales vs. textuales

Un lenguaje visual de programación como Scratch utiliza bloques de colores encajables para representar instrucciones. Cada bloque corresponde a una instrucción concreta: mover un personaje, reproducir un sonido o comprobar una condición. La principal ventaja es que elimina la sintaxis: no podéis escribir mal un bloque porque simplemente encaja o no encaja.

Un lenguaje textual como Python utiliza palabras y símbolos escritos con un teclado. Debéis escribir el código con una sintaxis estricta: cada carácter importa, las mayúsculas se distinguen de las minúsculas y el orden de las palabras determina qué hace el programa. A cambio, tenéis mucha más potencia y flexibilidad.

  • Ventajas de los bloques: Eliminan errores de sintaxis, son intuitivos, permiten centrarse en la lógica.
  • Inconvenientes de los bloques: Limitados a lo que el entorno permite, difícil de exportar, no se usa en la industria.
  • Ventajas del código textual: Potencia ilimitada, estándar profesional, multiplataforma, bibliotecas extensas.
  • Inconvenientes del código textual: Curva de aprendizaje de la sintaxis, más fácil cometer errores, requiere atención al detalle.
Consejo No tenéis miedo de cometer errores al escribir código. Todos los programadores profesionales cometen errores constantemente. Lo importante es saber encontrarlos y corregirlos.

Ejemplo comparativo: Scratch vs. Python

Comparemos un programa sencillo: hacer que un personaje diga "Hola mundo" y se mueva 10 pasos.

En Scratch: Arrastráis el bloque "decir Hola mundo" y debajo el bloque "mover 10 pasos". No hay forma de equivocarse.

En Python: Escribís print("Hola mundo") en una línea y print("Me muevo 10 pasos") en la siguiente. Si os falla una comilla o ponéis un paréntesis de más, el programa no funcionará.

Generación de programas: código fuente a código máquina

Introducción

Cuando escribís un programa en Python, estáis creando código fuente: un archivo de texto que contiene instrucciones legibles para los humanos. Pero el procesador de vuestro ordenador no entiende Python ni ningún otro lenguaje de alto nivel. Solo entiende código máquina, una secuencia de unos y ceros. En esta sesión vamos a descubrir cómo se transforma vuestro código en algo que el ordenador pueda ejecutar realmente.

El proceso de generación de un programa

Cuando ejecutáis un programa en Python, ocurre lo siguiente:

  1. Código fuente: Escribís el programa en un archivo .py.
  2. Intérprete/Compilador: Python lee el código fuente, verifica que la sintaxis sea correcta y lo traduce a un formato intermedio.
  3. Código byte (interpretado): En Python, el código se compila a código byte, un formato intermedio que el intérprete puede ejecutar.
  4. Ejecución: La máquina virtual de Python (CPython) ejecuta el código byte instrucción por instrucción.

Python es un lenguaje interpretado, no compilado al uso tradicional. La diferencia es que un compilador tradicional (como C o Java) genera un ejecutable completo antes de ejecutar, mientras que Python traduce y ejecuta línea por línea.

Dato curioso Python usa un sistema de ejecución intermedio: el código se compila a código byte (.pyc) que luego ejecuta una máquina virtual. Esto combina la portabilidad de la interpretación con parte de la eficiencia de la compilación.

Estructura de un programa: E/S/P

Todo programa, sin importar su complejidad, sigue la estructura básica Entrada → Proceso → Salida:

  • Entrada (Input): Datos que el programa recibe del usuario o de fuentes externas. En Python: input().
  • Proceso: Operaciones que el programa realiza con los datos: cálculos, comparaciones, decisiones, bucles.
  • Salida (Output): Resultados que el programa muestra al usuario. En Python: print().

Esta estructura es universal. Desde un简单的 calculador hasta un sistema de inteligencia artificial, todos los programas siguen este flujo de información.

Práctica: flujo E/S/P

Cread un programa que:

  1. Pida al usuario su nombre (input()).
  2. Pida su edad (int(input())).
  3. Calcule en qué año cumplirá 100 años.
  4. Muestre el resultado con un mensaje (print()).
Reflexión Si Python es interpretado, ¿por qué no usamos siempre Python en lugar de C o C++? La respuesta es eficiencia: los lenguajes compilados generan código máquina directo y son mucho más rápidos en tareas críticas como videojuegos 3D o sistemas operativos.

Tipos de datos: variables, identificador, tipo y valor

Nota didáctica Los tipos de datos son la base de toda programación. Es crucial que los alumnos entiendan que en Python las variables no necesitan declarar su tipo explícitamente, pero el tipo siempre existe internamente.

¿Qué es una variable?

Una variable es un espacio en memoria donde almacenamos un dato. Se le asigna un nombre (identificador) y un valor. Podemos imaginarlo como una caja etiquetada: la etiqueta es el nombre y lo que hay dentro es el valor.

En Python, para crear una variable simplemente escribimos:

nombre = "Lucía"
edad = 15
altura = 1.68
es_mayor = True

No hace falta indicar el tipo de dato. Python lo infiere automáticamente a partir del valor asignado. A esto se le llama tipado dinámico.

Identificador, tipo y valor

Cada variable tiene tres componentes:

  • Identificador: El nombre de la variable. Debe empezar con letra o guión bajo, puede contener letras, números y guión bajo, y es case-sensitive (nombre ≠ Nombre).
  • Tipo: El tipo de dato que almacena. En Python se determina automáticamente.
  • Valor: El dato concreto almacenado en la variable.
Importante En Python no se puede usar una variable antes de asignarle un valor. Si intentáis imprimir una variable no definida, obtendréis un error NameError.

Tipos de datos principales

  • Números enteros (int): edad = 15, año = 2026.
  • Números decimales (float): altura = 1.68, nota = 8.75.
  • Cadenas de texto (str): nombre = "Lucía", curso = '3º ESO'.
  • Booleanos (bool): aprobado = True, repetido = False.
  • Listas (list): mascotas = ["Luna", "Max", "Nala"]. Colección ordenada de elementos.

Ejemplo con mascotas

# Lista de mascotas
mascotas = ["Luna", "Max", "Nala", "Rocky"]
print(f"Tengo {len(mascotas)} mascotas")
print(f"La primera se llama {mascotas[0]}")
print(f"La última se llama {mascotas[-1]}")

# Añadir una mascota
mascotas.append("Bella")
print(f"Ahora tengo {len(mascotas)} mascotas")

Operadores: aritméticos, relacionales y lógicos

Introducción

Los operadores son símbolos especiales que realizan operaciones sobre datos. Son las herramientas fundamentales para procesar información dentro de un programa. En esta sesión aprenderemos los tres tipos principales: aritméticos, relacionales y lógicos.

Operadores aritméticos

Realizan operaciones matemáticas básicas:

  • + Suma: 5 + 3 → 8
  • - Resta: 5 - 3 → 2
  • * Multiplicación: 5 * 3 → 15
  • / División: 5 / 2 → 2.5
  • % Módulo (resto): 5 % 2 → 1
  • // División entera: 5 // 2 → 2
  • ** Potencia: 5 ** 2 → 25

Operadores relacionales

Comparan dos valores y devuelven True o False:

  • > Mayor que
  • < Menor que
  • >= Mayor o igual que
  • <= Menor o igual que
  • == Igual a (comparación, NO asignación)
  • != Distinto de

Cuidado: = es asignación, == es comparación. Es el error más común entre principiantes.

Atención En Python 2 existía un operador de división entera distinto. En Python 3, / siempre devuelve un decimal y // devuelve la parte entera.

Operadores lógicos

Combinan expresiones booleanas:

  • and AND: Verdadero solo si ambas condiciones son verdaderas.
  • or OR: Verdadero si al menos una condición es verdadera.
  • not NOT: Invierte el valor booleano.

Ejemplo práctico

# Calculadora básica
a = 10
b = 3

print(f"Suma: {a} + {b} = {a + b}")
print(f"Resta: {a} - {b} = {a - b}")
print(f"Multiplicación: {a} * {b} = {a * b}")
print(f"División: {a} / {b} = {a / b}")
print(f"Módulo: {a} % {b} = {a % b}")

# Comparaciones
print(f"¿{a} es mayor que {b}? {a > b}")
print(f"¿{a} es igual a {b}? {a == b}")

Introducción a Python: palabras reservadas, comentarios, print(), input(), f-strings

Nota didáctica Esta sesión consolida los fundamentos del lenguaje Python. Es la sesión donde los alumnos aprenden a escribir código Python de forma autónoma, combinando entrada, proceso y salida de datos.

Palabras reservadas

Python tiene un conjunto de palabras reservadas que no pueden usarse como nombres de variables. Estas palabras tienen significados especiales en el lenguaje. Algunas de las más importantes:

False   class    finally    is        return
None    continue for        lambda    try
True    def      from       nonlocal  while
and     del      global     not       with
as      elif     if         or        yield
assert  else     import     pass
break   except   in         raise

Podéis ver la lista completa con import keyword; print(keyword.kwlist).

Comentarios

Los comentarios son texto ignorado por el intérprete. Sirven para explicar qué hace el código:

# Esto es un comentario de una línea
# El intérprete lo ignora completamente

print("Hola")  # También se puede comentar al final de una línea

"""
Esto es un comentario
de varias líneas (docstring).
Se usa para documentar funciones y módulos.
"""

Función print()

print() muestra información por pantalla. Es la forma más básica de salida:

print("Hola mundo")
print("Nombre:", "Lucía", "Edad:", 15)
print("Salto de línea\nAquí abajo")
print("Sin salto", end=" ")
print("en la misma línea")

Función input()

input() lee datos del teclado. Siempre devuelve una cadena de texto (str):

nombre = input("¿Cómo te llamas? ")
edad = int(input("¿Cuántos años tienes? "))
altura = float(input("¿Cuánto mides? "))

Nunca olvidéis convertir los números con int() o float(). Si no lo hacéis, operaréis con texto en lugar de números.

f-strings (cadenas formateadas)

Las f-strings permiten insertar valores de variables directamente en un texto, usando llaves {}:

nombre = "Lucía"
edad = 15

# Sin f-strings (antes)
print("Me llamo " + nombre + " y tengo " + str(edad) + " años")

# Con f-strings (ahora)
print(f"Me llamo {nombre} y tengo {edad} años")

# Operaciones dentro de f-strings
print(f"El doble de mi edad es {edad * 2}")

Estructuras condicionales: if, elif, else

Introducción

Los programas deben tomar decisiones. En Scratch, ya usabais el bloque "si...entonces" con una forma de rombo. En Python, la estructura equivalente es if, pero en lugar de arrastrar bloques, escribiremos código con una regla fundamental: la sangría (indentación) determina qué código se ejecuta condicionalmente.

Estructura if-else

edad = int(input("¿Cuántos años tienes? "))

if edad >= 18:
    print("Eres mayor de edad")
    print("Puedes votar")
else:
    print("Eres menor de edad")
    print("Aún no puedes votar")

Fijaos en dos cosas clave:

  • Después de la condición siempre hay dos puntos (:).
  • El código que se ejecuta condicionalmente va indentado (4 espacios).
Importante: Sangría en Python La indentación no es opcional en Python, es obligatoria. Si no indentáis correctamente, obtendréis un error de indentación. Usad siempre 4 espacios (no mezcléis tabs y espacios). Esto diferencia Python de otros lenguajes como Java o C, que usan llaves {} para delimitar bloques de código.

elif: múltiples condiciones

Cuando tenéis más de dos opciones, usáis elif (abreviación de "else if"):

nota = float(input("Introduce tu nota (0-10): "))

if nota >= 9:
    print("Sobresaliente")
elif nota >= 7:
    print("Notable")
elif nota >= 5:
    print("Aprobado")
elif nota >= 4:
    print("Insuficiente")
else:
    print("Muy deficiente")

Operadores and / or en condiciones

Podéis combinar varias condiciones en una misma sentencia:

edad = int(input("Edad: "))
tiene_permiso = input("¿Tienes permiso? (s/n): ") == "s"

if edad >= 16 and tiene_permiso:
    print("Puedes conducir")
elif edad >= 16 and not tiene_permiso:
    print("Necesitas permiso de tus padres")
else:
    print("Eres demasiado joven")

Condiciones anidadas

Podéis incluir un if dentro de otro if. Pero evitad más de 2 niveles de anidación porque el código se vuelve difícil de leer.

Bucles while y for, range(), iterar listas. Funciones con def

Nota didáctica Los bucles y las funciones son los dos pilares que convierten un script simple en un programa real. En esta sesión cerramos la unidad unificando todos los conceptos aprendidos.

Bucle while

El bucle while repite un bloque de código mientras una condición sea verdadera:

intentos = 0
password = ""

while password != "python123":
    password = input("Introduce la contraseña: ")
    intentos += 1

print(f"Correcto. Intentos: {intentos}")

Cuidado: si la condición nunca se hace falsa, el bucle se ejecuta para siempre (bucle infinito). Siempre debéis tener una forma de salir.

Peligro Un bucle infinito puede congelar vuestro programa. Si os ocurre, pulsad Ctrl+C en la terminal para detenerlo. Siempre verificar que la condición del while puede hacerse falsa.

Bucle for y range()

El bucle for recorre una secuencia de valores. Es ideal para repetir algo un número conocido de veces:

# Contar del 1 al 5
for i in range(1, 6):
    print(i)

# Tabla del 7
for i in range(1, 11):
    print(f"7 x {i} = {7 * i}")

# Invertir un rango
for i in range(10, 0, -1):
    print(i)
print("¡Despegue!")

Iterar listas

También podemos recorrer elementos de una lista directamente:

mascotas = ["Luna", "Max", "Nala", "Rocky"]

for mascota in mascotas:
    print(f"Mi mascota se llama {mascota}")

# Con índices
for i in range(len(mascotas)):
    print(f"Mascota {i + 1}: {mascotas[i]}")

Funciones con def

Las funciones permiten agrupar código reutilizable. Definís una función con def, le dais un nombre, podéis pasarle parámetros y devolver un resultado con return:

def saludar(nombre):
    """Saluda a una persona."""
    print(f"¡Hola, {nombre}! Bienvenido a Python.")

def calcular_area(base, altura):
    """Calcula el área de un rectángulo."""
    return base * altura

# Usar las funciones
saludar("Lucía")
area = calcular_area(5, 3)
print(f"El área es: {area}")

Ejercicio resuelto: adivina el número

import random

def adivina_el_numero():
    secreto = random.randint(1, 20)
    intentos = 0
    adivinado = False

    print("¡Adivina el número entre 1 y 20!")

    while not adivinado and intentos < 5:
        num = int(input("Tu intento: "))
        intentos += 1

        if num == secreto:
            adivinado = True
            print(f"¡Correcto! Lo lograste en {intentos} intentos")
        elif num < secreto:
            print("Demasiado bajo")
        else:
            print("Demasiado alto")

    if not adivinado:
        print(f"Perdiste. El número era {secreto}")

adivina_el_numero()
