¿Qué es programar? Algoritmos y características

Nota didáctica Esta sesión es la puerta de entrada al mundo de la programación. Es fundamental que el alumnado comprenda que un algoritmo no es algo exclusivo de los ordenadores, sino una forma estructurada de resolver problemas que utilizamos en la vida cotidiana.

Introducción

¿Alguna vez habéis seguido una receta de cocina? ¿Habéis ensamblado un mueble de IKEA siguiendo las instrucciones? En ambos casos habéis ejecutado un algoritmo: una secuencia ordenada de pasos para alcanzar un objetivo concreto. Hoy vamos a descubrir qué es exactamente un algoritmo, cuáles son sus características fundamentales y cómo se relaciona con la programación de ordenadores.

Comenzaremos con una actividad práctica: construir un avión de papel siguiendo instrucciones paso a paso. A partir de esta experiencia, analizaremos qué funciona, qué falla y cómo podríamos mejorar las instrucciones para que cualquier persona pueda reproducir el resultado.

¿Qué es un algoritmo?

Un algoritmo es un conjunto finito, ordenado y finito de instrucciones o reglas bien definidas que permiten realizar una tarea o resolver un problema concreto. La palabra proviene del matemático persa Al-Khwarizmi (siglo IX), considerado el padre del álgebra.

Para que un algoritmo sea válido debe cumplir tres características esenciales:

  • Finito: Debe terminar en algún momento. Un algoritmo que nunca termina no tiene utilidad práctica.
  • Definido: Cada paso debe estar perfectamente especificado. No puede haber ambigüedades ni interpretaciones.
  • Preciso: Cada instrucción debe realizar exactamente una acción concreta. No puede haber margen de duda sobre qué hacer.
Actividad práctica En parejas de 2 alumnos, escribid las instrucciones paso a paso para construir un avión de papel. Luego, intercambiad las instrucciones con otro grupo y comprobad si son lo suficientemente claras para que cualquiera pueda seguir sin dudas.

Algoritmos en la vida cotidiana

Los algoritmos nos rodean más de lo que parece:

  • Recetas de cocina: Ingredientes (datos) + pasos (instrucciones) = plato terminado (resultado).
  • Ruta para ir al instituto: Salir de casa → girar a la derecha → cruzar el semáforo → llegar al edificio.
  • Ordenar una baraja: Separar por palos, luego ordenar cada palo por número.
  • Algoritmos de búsqueda: Buscar un nombre en la guía telefónica abriendo por la mitad (búsqueda binaria).

De algoritmo a programa

Un programa informático es esencialmente un algoritmo escrito en un lenguaje que el ordenador puede entender. El proceso de creación sigue estas fases:

  1. Definir el problema: ¿Qué queremos resolver?
  2. Diseñar el algoritmo: Escribir los pasos en lenguaje natural o pseudocódigo.
  3. Codificar: Traducir el algoritmo a un lenguaje de programación.
  4. Probar y depurar: Ejecutar el programa y corregir errores.
  5. Mantener: Actualizar y mejorar el programa según las necesidades.
Recuerda Un error común es confundir un algoritmo con un programa. El algoritmo es la idea abstracta; el programa es su implementación concreta en un lenguaje de programación.

Secuencia de instrucciones y representación de algoritmos

Nota didáctica Los medios de expresión de algoritmos son herramientas fundamentales para comunicar la lógica de un programa antes de escribir código. Dominar el pseudocódigo y los diagramas de flujo facilita enormemente la fase de diseño.

Introducción

Antes de escribir una sola línea de código, es habitual diseñar el algoritmo utilizando herramientas de representación. En esta sesión aprenderemos tres medios de expresión de algoritmos: el lenguaje natural, el pseudocódigo y los diagramas de flujo. Cada uno tiene sus ventajas y se usa en diferentes contextos.

Lenguaje natural

Es la forma más intuitiva de expresar un algoritmo: escribir los pasos en nuestro idioma habitual. Es accesible para cualquier persona, pero presenta problemas importantes:

  • Ambigüedad: Las palabras pueden tener diferentes interpretaciones según el contexto.
  • Verbosidad: Requiere muchas palabras para expresar conceptos simples.
  • Falta de precisión: No es adecuado para algoritmos complejos donde cada detalle importa.

Ejemplo: "Para hacer un sándwich, toma dos rebanadas de pan, pon queso en una de ellas, cubre con la otra rebanada y sirve."

Pseudocódigo

El pseudocódigo es una representación semiformal de un algoritmo que utiliza una combinación de lenguaje natural y elementos estructurados. No sigue una sintaxis estricta, pero es más preciso que el lenguaje natural:

  • Utiliza palabras clave como INICIO, FIN, SI, ENTONCES, MIENTRAS, HACER.
  • Es independiente del lenguaje de programación.
  • Facilita la traducción a cualquier lenguaje de programación.
Ejemplo de pseudocódigo INICIO
  LEER "¿Cómo te llamas?" → nombre
  SI nombre ≠ "" ENTONCES
    ESCRIBIR "¡Hola, " + nombre + "!"
  SI NO
    ESCRIBIR "No has introducido tu nombre"
  FIN SI
FIN

Diagrama de flujo

Un diagrama de flujo es una representación gráfica de un algoritmo utilizando figuras geométricas conectadas con flechas. Cada forma tiene un significado específico:

  • Óvalo: Inicio y fin del algoritmo.
  • Paralelogramo: Entrada o salida de datos (leer/escribir).
  • Rectángulo: Proceso o instrucción (asignaciones, cálculos).
  • Diamante: Decisión (pregunta con respuesta SI/NO).
  • Flechas: Dirección del flujo de ejecución.

Actividad práctica

Dibujaremos un diagrama de flujo para resolver el problema de calcular si un número es par o impar. Luego, escribiremos el pseudocódigo correspondiente y lo compararemos con la implementación en Scratch.

Primer contacto con Python: del bloque al código

Nota didáctica Es posible que solo hayáis tocado Scratch un poquito, o incluso que no lo recuerdeis: no pasa nada. Solo necesitamos la idea básica de que programar es dar instrucciones a un ordenador, y ahora lo haremos escribiendo texto en Python.

Introducción

En Scratch, si lo habéis visto, se programa arrastrando bloques de colores y encajándolos unos con otros: cada bloque es una instrucción y encaja porque el programa sabe qué va después. En Python hacemos exactamente lo mismo, pero escribiendo el código con el teclado. La lógica es la misma; cambia la forma de expresarla.

Lo bueno de Python es que su código se parece bastante a lo que leerías en castellano, así que en muy pocas sesiones podréis escribir programas de verdad.

La misma idea, dos formas de programar

Si algún día habéis abierto Scratch, estas son las equivalencias que necesitáis. Si no lo habéis visto, esta tabla os sirve igualmente para ver qué hace cada cosa en Python:

Queremos… En Scratch (si lo recuerdas) En Python
Mostrar un mensajeBloque "decir Hola"print("Hola")
Crear una variableBotón "Variables"nombre = "Lucía"
Preguntar al usuarioBloque "preguntar y esperar"respuesta = input("¿Cuál es tu nombre? ")

El entorno de trabajo: Thonny

Escribiremos nuestro código en Thonny, un editor sencillo y gratuito. Su uso básico es muy fácil:

  • Escribir: se teclea el código en el área superior.
  • Ejecutar: se pulsa el botón ▶ (o F5) y el resultado aparece abajo.
  • Leer errores: si algo falla, Thonny marca la línea en rojo y explica el problema. Fallar es parte de aprender: todos los programadores depuran errores a diario.

Comentarios

Un comentario es texto que el ordenador ignora; solo sirve para que quien lea el código entienda qué hace:

# Esto es un comentario de una línea
print("Hola")  # También se puede comentar al final

Función print(): mostrar por pantalla

print() muestra información por pantalla. Es lo más parecido al bloque "decir" de Scratch:

print("Hola mundo")
print("Nombre:", "Lucía", "Edad:", 15)

Función input(): leer datos del usuario

input() detiene el programa y espera a que el usuario escriba algo. Siempre devuelve texto, aunque escriba números:

nombre = input("¿Cómo te llamas? ")
edad = int(input("¿Cuántos años tienes? "))  # convertir a número

Si vamos a hacer cálculos, debemos convertir con int() o float(); si no, Python tratará los números como texto.

Variables y tipos de datos

Nota didáctica Si en Scratch habíais usado el botón "Variables" para guardar una puntuación, ya conocéis el concepto. En Python es igual, solo que la variable se crea con una sola línea: nombre = valor.

¿Qué es una variable?

Una variable es un espacio en memoria donde guardamos un dato. Pensad en una caja etiquetada: la etiqueta es el nombre y lo que hay dentro es el valor.

En Python basta con escribir:

nombre = "Lucía"
edad = 15
altura = 1.68
es_mayor = True

No hace falta indicar el tipo: Python lo deduce solo. A esto se le llama tipado dinámico.

Identificador, tipo y valor

  • Identificador: el nombre. Empieza por letra o _, puede llevar letras, números y guiones bajos, y distingue mayúsculas (nombre ≠ Nombre).
  • Tipo: qué clase de dato guarda (en Python se detecta automáticamente).
  • Valor: el dato concreto guardado.
Importante No se puede usar una variable antes de darle un valor. Si imprimís una variable no definida, obtendréis un error NameError.

Tipos de datos principales

  • Enteros (int): edad = 15.
  • Decimales (float): altura = 1.68.
  • Texto (str): nombre = "Lucía".
  • Booleanos (bool): aprobado = True o False.
  • Listas (list): mascotas = ["Luna", "Max"], colección ordenada.

Mostrar variables con f-strings

Las f-strings permiten insertar el valor de una variable dentro de un texto usando llaves {}:

nombre = "Lucía"
edad = 15

print(f"Me llamo {nombre} y tengo {edad} años")
print(f"El doble de mi edad es {edad * 2}")

Ejemplo con una lista

mascotas = ["Luna", "Max", "Nala", "Rocky"]
print(f"Tengo {len(mascotas)} mascotas")
print(f"La primera se llama {mascotas[0]}")

mascotas.append("Bella")
print(f"Ahora tengo {len(mascotas)} mascotas")

Operadores: aritméticos, relacionales y lógicos

Introducción

Los operadores son los símbolos con los que procesamos datos. Si en Scratch las comparaciones y las operaciones matemáticas eran bloques especiales, en Python se escriben directamente: son casi los mismos símbolos que usáis en la calculadora.

Operadores aritméticos

Operador Significado Ejemplo
+Suma5 + 3 → 8
-Resta5 - 3 → 2
*Multiplicación5 * 3 → 15
/División5 / 2 → 2.5
%Módulo (resto)5 % 2 → 1
//División entera5 // 2 → 2
**Potencia5 ** 2 → 25

Operadores relacionales

Comparan dos valores y devuelven True (verdadero) o False (falso):

  • > mayor que · < menor que
  • >= mayor o igual · <= menor o igual
  • == igual a (comparar) · != distinto de

Cuidado: = asigna un valor y == compara. Es el error más común de los principiantes.

Operadores lógicos

Sirven para combinar varias condiciones:

  • and: verdadero solo si ambas condiciones son verdaderas.
  • or: verdadero si al menos una es verdadera.
  • not: invierte el resultado.

Ejemplo práctico

a = 10
b = 3

print(f"Suma: {a} + {b} = {a + b}")
print(f"División: {a} / {b} = {a / b}")
print(f"¿{a} es mayor que {b}? {a > b}")
print(f"¿{a} es igual a {b}? {a == b}")

Estructuras condicionales: if, elif, else

Introducción

Los programas deben tomar decisiones: si llueve llevo paraguas, si no, no. En Scratch eso era el bloque "si…entonces" con forma de rombo; en Python la sentencia es if. Lo único nuevo es que Python marca qué código pertenece al if mediante la sangría (el espacio de la izquierda), no con bloques encajados.

Estructura if-else

edad = int(input("¿Cuántos años tienes? "))

if edad >= 18:
    print("Eres mayor de edad")
    print("Puedes votar")
else:
    print("Eres menor de edad")
    print("Aún no puedes votar")
  • Tras la condición van dos puntos (:).
  • El código de dentro va indentado (4 espacios).
Importante: la sangría En Python la indentación no es opcional: marca el principio y el fin de cada bloque. Si no indentáis bien, obtendréis un error de indentación. Usad siempre 4 espacios y no mezcléis tabs con espacios.

elif: varias condiciones

Cuando hay más de dos opciones se usa elif (de "else if"):

nota = float(input("Introduce tu nota (0-10): "))

if nota >= 9:
    print("Sobresaliente")
elif nota >= 7:
    print("Notable")
elif nota >= 5:
    print("Aprobado")
else:
    print("Suspenso")

Combinar condiciones con and / or

edad = int(input("Edad: "))
llueve = input("¿Llueve? (s/n): ") == "s"

if edad >= 16 and not llueve:
    print("Puedes salir en bici")
elif llueve:
    print("Mejor quédate en casa")
else:
    print("Eres demasiado joven")

Podéis anidar un if dentro de otro, pero evitad pasar de 2 niveles: el código se vuelve difícil de leer.

Bucles y funciones: repetir y reutilizar código

Nota didáctica Si en Scratch existían los bloques "repetir N veces" y "por siempre", aquí veremos sus equivalentes: los bucles for y while. Con ellos y las funciones cerramos la unidad uniendo todo lo aprendido.

Bucle while: repetir mientras se cumpla

El bucle while repite un bloque mientras una condición sea verdadera:

password = ""

while password != "python123":
    password = input("Introduce la contraseña: ")

print("¡Correcto!")

Si la condición nunca se hace falsa, el bucle no acaba nunca. Siempre debe existir una forma de salir.

Peligro Un bucle infinito puede congelar vuestro programa. Si os ocurre, pulsad Ctrl+C en la terminal para detenerlo.

Bucle for y range(): repetir un número de veces

El for recorre una secuencia de valores; es el equivalente al bloque "repetir N veces":

# Contar del 1 al 5
for i in range(1, 6):
    print(i)

# Tabla del 7
for i in range(1, 11):
    print(f"7 x {i} = {7 * i}")

Iterar listas

mascotas = ["Luna", "Max", "Nala"]

for mascota in mascotas:
    print(f"Mi mascota se llama {mascota}")

Funciones con def: código reutilizable

Las funciones agrupan código con un nombre para reutilizarlo tantas veces como haga falta. Se definen con def y pueden devolver un resultado con return:

def saludar(nombre):
    print(f"¡Hola, {nombre}! Bienvenido a Python.")

def calcular_area(base, altura):
    return base * altura

saludar("Lucía")
print(f"El área es: {calcular_area(5, 3)}")

Ejercicio resuelto: adivina el número

import random

secreto = random.randint(1, 20)
intentos = 0

print("¡Adivina el número entre 1 y 20!")

while intentos < 5:
    num = int(input("Tu intento: "))
    intentos += 1

    if num == secreto:
        print(f"¡Correcto en {intentos} intentos!")
        break
    elif num < secreto:
        print("Demasiado bajo")
    else:
        print("Demasiado alto")
else:
    print("Perdiste. El número era", secreto)
